   - Add JSDoc with example: `sound.fadeIn(2) // fade in over 2 seconds`

   - IMPORTANT: `_trackedTimeout` is private on BaseSound, so fadeOut (also on BaseSound) CAN access it directly. No visibility change needed.
   - Add JSDoc with example: `await sound.fadeOut(2) // fade out over 2 seconds then stop`

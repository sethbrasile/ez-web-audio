**SAFE-01 — Fire-and-forget error handling:**

In `src/base-sound.ts`:
1. `playIn()` currently calls `this.playAt(...)` which returns a Promise that is discarded. Change to:
   ```typescript
   public playIn(when: number): void {
     void this.playAt(this.audioContext.currentTime + when).catch(() => {})
   }
   ```
   The `void` + `.catch(() => {})` pattern silently catches rejections — the user called a void-returning method so there is no way to propagate the error. The `void` operator satisfies linters that flag floating promises.

2. `playFor()` — same pattern. The `this.playAt(...)` call on line ~834 becomes:
   ```typescript
   void this.playAt(this.audioContext.currentTime).catch(() => {})
   ```

3. `playInAndStopAfter()` — calls `this.playIn(playIn)` which now handles errors internally. No change needed here since `playIn` already handles it.

In `src/sampler.ts`:
4. `play()` on line ~83 calls `this.getNextSound().play()` which returns a Promise. Change to:
   ```typescript
   public play(): void {
     void this.getNextSound().play().catch(() => {})
   }
   ```
5. `playIn()` — same: `void this.getNextSound().playIn(seconds)` — but `playIn` on BaseSound is already void and now catches internally. However, Sampler calls `playIn` on a `Playable` which may throw synchronously from `getNextSound()`. Leave `playIn` as-is since BaseSound.playIn now catches internally.
6. `playAt()` — same pattern: the result of `playAt()` is a Promise. Change to:
   ```typescript
   public playAt(time: number): void {
     void this.getNextSound().playAt(time).catch(() => {})
   }
   ```

In `src/track.ts`:
7. `resume()` on line ~222 calls `this.play()` which returns a Promise. Change to:
   ```typescript
   void this.play().catch(() => {})
   ```

**SAFE-04 — percentPlayed divide-by-zero guard:**

```typescript
public get percentPlayed(): number {
  const duration = this.duration.raw
  if (duration === 0) return 0
  return (this.startOffset / duration) * 100
}
```

**SAFE-05 — seek race condition guard:**

In `src/track.ts`, add a private `_seekId` counter (initialized to 0). In the `seek()` method's `moveToOffset` async function:
1. At the start of `moveToOffset`, increment `_seekId` and capture the value: `const seekId = ++this._seekId`
2. After `await this.stop()`, check if `seekId === this._seekId`. If not, return early (a newer seek has superseded this one).

This ensures last-seek-wins: only the most recent seek writes `startOffset`.

```typescript
private _seekId = 0

// Inside moveToOffset:
const seekId = ++this._seekId
// ... existing logic ...
if (_isPlaying) {
  await this.stop()
  if (seekId !== this._seekId) return  // superseded by newer seek
  this.startOffset = adjustedOffset
  this.later(() => this.play())
}
```

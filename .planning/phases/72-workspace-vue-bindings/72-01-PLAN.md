# 72-01: pnpm Workspace Conversion

> **For agentic workers:** Execute per `.planning/M8-PLAYBOOK.md` (Opus orchestrator + implementer subagents). Steps use checkbox syntax for tracking.

**Goal:** Convert the repo to a pnpm workspace: `packages/core` (the existing library, npm name `ez-web-audio` unchanged), `packages/vue` + `packages/react` (empty stubs), docs staying at `/docs` consuming workspace packages — with every existing script and CI job still green.

**Architecture:** Root package becomes `private: true` orchestration shell holding docs/e2e tooling. Library code, its co-located tests, and its build config move wholesale to `packages/core`. Docs resolves `ez-web-audio` via `workspace:*` dependency (imports in demo components stay untouched — they already import by package name).

**Tech stack:** pnpm workspaces, Vite lib build, Vitest, VitePress, Playwright, TypeDoc.

## Global Constraints

- All packages version `0.2.0`, version-locked. Never 1.0.
- Package names exactly: `ez-web-audio`, `@ez-web-audio/vue`, `@ez-web-audio/react`.
- No new runtime dependencies.
- Root commands must keep working: `pnpm dev`, `pnpm build`, `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm test:e2e`.
- Demo components' `import ... from 'ez-web-audio'` lines must NOT change in this plan.

### Task 4: Multi-package publish CI

**Files:**
- Modify: `.github/workflows/publish.yml`

**Interfaces:**
- Consumes: workspace layout; Produces: tag `v*` publishes all three public packages, version-lock enforced.

- [ ] **Step 1: Update workflow** — keep existing gate steps (typecheck, lint, unit, build, E2E). Replace the tag-check + publish steps:

```yaml
      - name: Verify git tag matches all package versions
        run: |
          TAG_VERSION="${GITHUB_REF#refs/tags/v}"
          for PKG in packages/core packages/vue packages/react; do
            PKG_VERSION=$(node -p "require('./${PKG}/package.json').version")
            if [ "$TAG_VERSION" != "$PKG_VERSION" ]; then
              echo "::error::Tag v${TAG_VERSION} != ${PKG} version ${PKG_VERSION}"; exit 1
            fi
          done

      - name: Publish all packages
        run: pnpm -r publish --access public --no-git-checks
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
          NPM_CONFIG_PROVENANCE: 'true'
```

Note: `pnpm -r publish` skips the private root and converts `workspace:` protocol to real versions on pack.

- [ ] **Step 2: Verify locally without publishing:** `pnpm -r publish --dry-run --access public --no-git-checks`
Expected: lists ez-web-audio, @ez-web-audio/vue, @ez-web-audio/react at 0.2.0; skips root. (Scoped dry-run may warn the org doesn't exist yet — acceptable; org creation is human gate 4.)

- [ ] **Step 3: Commit** — `ci: publish all workspace packages on version tags`

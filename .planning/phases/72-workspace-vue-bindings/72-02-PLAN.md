# 72-02: @ez-web-audio/vue Composables

> **For agentic workers:** Execute per `.planning/M8-PLAYBOOK.md`. TDD throughout — test first, watch it fail, implement, watch it pass, commit.

**Goal:** Build `@ez-web-audio/vue`: SSR-safe composables wrapping every core factory with a uniform `{ instance, loading, error, load }` shape, plus `useCleanup()` auto-disposal and `useAudioContext()` init state — the package all docs demos refactor onto in Phase 73.

**Architecture:** One generic `createFactoryComposable` produces all factory wrappers (DRY). `useCleanup` owns disposal on unmount — this is the structural fix for the deep-review patterns `demo-resource-cleanup-inconsistency` and `demo-audio-init-duplication`. Nothing touches an AudioContext until a user-triggered `load()`/`init()` — safe under VitePress SSR.

**Tech stack:** Vue 3 (peer), Vite lib build, Vitest + happy-dom. Unit tests stub factories — no audio mocking needed.

## Global Constraints

- Runtime deps: none. Peers: `ez-web-audio`, `vue ^3.4`.
- Every composable importable individually; package `sideEffects: false`, tree-shakeable.
- No AudioContext access at module scope or during setup() — only inside `load()`/`init()`.
- Uniform return shape (exact, relied on by Phases 73/76/77): `instance: ShallowRef<T | null>`, `loading: Ref<boolean>`, `error: Ref<Error | null>`, `load(...args): Promise<T>`.

```ts
import { getCurrentInstance, onUnmounted } from 'vue'

export interface Disposable {
  dispose?: () => void
  stop?: () => void
}

export function useCleanup() {
  const disposables = new Set<Disposable>()

  function register<T extends Disposable>(d: T): T {
    disposables.add(d)
    return d
  }

  function disposeAll(): void {
    for (const d of disposables) {
      try { d.stop?.() }
      catch (e) { console.warn('[ez-web-audio/vue] stop() failed during cleanup:', e) }
      try { d.dispose?.() }
      catch (e) { console.warn('[ez-web-audio/vue] dispose() failed during cleanup:', e) }
    }
    disposables.clear()
  }

  if (getCurrentInstance())
    onUnmounted(disposeAll)

  return { register, disposeAll }
}
```

- [ ] **Step 3: Implement:**

```ts
import type { Ref, ShallowRef } from 'vue'
import { ref, shallowRef } from 'vue'

export function createFactoryComposable<T, A extends unknown[]>(
  factory: (...args: A) => Promise<T>,
) {
  return function useFactory(): UseFactoryReturn<T, A> {
    const instance = shallowRef<T | null>(null)
    const loading = ref(false)
    const error = ref<Error | null>(null)
    let pending: Promise<T> | null = null

    function load(...args: A): Promise<T> {
      if (instance.value)
        return Promise.resolve(instance.value)
      if (pending)
        return pending
      loading.value = true
      error.value = null
      pending = factory(...args)
        .then((created) => { instance.value = created; return created })
        .catch((e) => {
          error.value = e instanceof Error ? e : new Error(String(e))
          throw e
        })
        .finally(() => { loading.value = false; pending = null })
      return pending
    }

    return { instance, loading, error, load }
  }
}
```

    Grid drawing function `drawGrid(x?: number, y?: number)`:
    - Clear canvas
    - Background: `#1a1a2e` (dark, works in both themes)
    - Subtle grid lines at octave boundaries on X-axis (100, 200, 400, 800, 1600 Hz positions), and 0.25 increments on Y-axis
    - Grid lines: `rgba(255,255,255,0.1)`
    - Axis labels: "Frequency -->" bottom center, "Gain" rotated on left (or just as text)
    - If x,y provided: draw crosshair (bright accent `#4a9eff`, 2px lines spanning full width/height, small circle at intersection)

    Frequency mapping (X-axis, logarithmic):
    - `frequency = 100 * Math.pow(20, ratio)` where ratio = x / canvasWidth
    - Range: 100-2000 Hz

    Gain mapping (Y-axis, inverted):
    - `gain = 1 - (y / canvasHeight)`
    - Range: 0-1

    Note name lookup:
    - Use a simple reverse lookup: find closest frequency in the 12-TET scale
    - Notes array with frequencies, find minimum distance

    Mouse/touch handlers:
    - mousedown: set isPlaying, init audio if needed, create oscillator, update position, play
    - mousemove: if isPlaying, update position (frequency + gain via `oscillator.update('frequency').to(freq).from('value')` and `oscillator.update('gain').to(gain).from('ratio')`)
    - mouseup / mouseleave: stop oscillator, set isPlaying false, redraw grid without crosshair
    - touchstart: same as mousedown (use `touch.clientX/Y` with `getBoundingClientRect()` offset, `preventDefault()`)
    - touchmove: same as mousemove
    - touchend: same as mouseup

    CRITICAL: Use `oscillator.update()` for parameter changes (not stop/restart) — avoids clicks per research.

    Sound synthesis functions (each creates and plays fresh oscillators):

    **Kick** — `async function playKick()`:
    ```typescript
    const osc = await lib.createOscillator({
      frequency: 150,
      type: 'triangle',
    })
    osc.onPlayRamp('frequency').from(150).to(0.01).in(0.1)
    osc.onPlayRamp('gain').from(1).to(0).in(0.1)
    osc.changeGainTo(0.8)
    osc.play()
    setTimeout(() => { try { osc.stop() } catch {} }, 200)
    ```

    **Snare** — `async function playSnare()`:
    Two layers:
    1. "Meat" — triangle oscillator, frequency ramp 100->60Hz, gain ramp 1->0 in 0.15s
    2. "Crack" — white noise with highpass filter at 1000Hz, gain ramp 1->0 in 0.15s
    Use `createWhiteNoise()` and `createFilterEffect(ctx, 'highpass', { frequency: 1000 })` for the crack.
    Play both simultaneously. Stop both after ~200ms.

    **Hi-Hat** — `async function playHiHat()`:
    Multiple square oscillators at harmonic ratios of 40Hz fundamental (e.g., 2x, 3x, 4.16x, 5.43x, 6.79x, 8.21x — metallic ratios).
    Apply highpass filter at 7000Hz. Quick gain envelope: ramp 0.3->0 in 0.08s.
    Create 6 oscillators, add highpass filter to each, play all, stop after 100ms.
    (Simplified approach: use 2-3 oscillators with bandpass/highpass instead of 6, if the full version is too complex for a demo. Use your judgment.)

    **Bass Drop** — `async function playBassDrop()`:
    Triangle oscillator, frequency sweep 100->0.01 Hz over 10 seconds, linear ramp.
    Gain: start at 0.6, ramp to 0 over 10s.
    ```typescript
    const osc = await lib.createOscillator({ frequency: 100, type: 'triangle' })
    osc.onPlayRamp('frequency').from(100).to(0.01).in(10)
    osc.onPlayRamp('gain').from(0.6).to(0).in(10)
    osc.play()
    ```

# 73-01: Refactor All Docs Demos onto @ez-web-audio/vue

> **For agentic workers:** Execute per `.planning/M8-PLAYBOOK.md`. One demo per task, one commit per demo. E2E suite is the referee.

**Goal:** Every audio-using docs demo component uses `@ez-web-audio/vue` composables for init and cleanup — zero behavior change — deleting the per-demo `ensureLoaded`/`onUnmounted` boilerplate that caused the 2026-03-19 deep-review leak findings.

**Architecture:** Mechanical transformation per the Refactor Contract below. Composables come from 72-02 (see its SUMMARY for the final inventory). Demos keep their own UI logic; only lifecycle/init/dispose plumbing changes.

## Global Constraints

- **Zero behavior change.** Full E2E suite green after every single demo commit. Any E2E edit beyond selector updates requires an orchestrator sign-off note in SUMMARY.
- No-load-button rule stands: first user interaction triggers `load()`.
- No `as any` on library types — the composables are typed; use them.
- Demo components import from `'@ez-web-audio/vue'` and `'ez-web-audio'` (types/values) — never relative paths into packages.

## The Refactor Contract (applies to every task)

For each demo component:

1. **Replace init plumbing.** Delete module/component-level `let lib: typeof EzWebAudio | null`, `ensureLoaded()` guards, and lazy `await import('ez-web-audio')` blocks. Use the matching composable(s); the previous `ensureLoaded()` body becomes the demo's `load()` call chain, still triggered by the same first user interaction.
2. **Replace disposal.** Delete manual `onUnmounted` stop/dispose blocks. Register every created instance: `cleanup.register(instance)`. Non-library resources (RAF loops, `document` listeners, ResizeObservers) stay in explicit `onUnmounted` — `useCleanup` is for library objects only.
3. **Preserve everything else.** UI state, watchers, canvas code, reactive patterns, template, styles: untouched unless a line existed solely to serve deleted plumbing.
4. **Verify:** `pnpm typecheck && pnpm lint` + the demo's E2E specs + a targeted `pnpm test:e2e` full run before commit.

**Worked example — the canonical shape** (style reference; the implementer reads the real file and applies the contract to what is actually there):

```ts
// BEFORE (typical M7 demo)
import type * as EzWebAudio from 'ez-web-audio'
let lib: typeof EzWebAudio | null = null
let osc: Oscillator | null = null
async function ensureLoaded() {
  if (lib) return
  lib = await import('ez-web-audio')
  osc = await lib.createOscillator({ frequency: 440 })
}
async function play() { await ensureLoaded(); osc!.play() }
onUnmounted(() => { osc?.stop(); osc?.dispose?.(); osc = null })

// AFTER
import { useCleanup, useOscillator } from '@ez-web-audio/vue'
const cleanup = useCleanup()
const { instance: osc, load: loadOsc } = useOscillator()
async function play() {
  const o = cleanup.register(await loadOsc({ frequency: 440 }))
  o.play()
}
// no onUnmounted for library objects — useCleanup handles it
```

### Task 2: Demo master bus util (TDD where unit-testable)

**Files:**
- Create: `docs/.vitepress/theme/audio/demo-master-bus.ts`
- Modify: `docs/.vitepress/theme/index.ts` (expose test hook)

**Interfaces:**
- Produces (consumed by every demo + Phase 76 + E2E):

```ts
export interface DemoMasterBus {
  input: AudioNode            // demos connect here
  peak: () => number          // max abs sample since last call, then resets (AnalyserNode-based)
  dispose: () => void
}
export function getDemoMasterBus(ctx: AudioContext): DemoMasterBus  // singleton per context
```

- [ ] **Step 1: Implement:** `input(GainNode) → DynamicsCompressorNode(limiter: threshold -1dB, knee 0, ratio 20, attack 0.001, release 0.05) → AnalyserNode → ctx.destination`. `peak()` reads `getFloatTimeDomainData` into a reused Float32Array, returns running max, resets. Singleton via `WeakMap<AudioContext, DemoMasterBus>`.
- [ ] **Step 2: Test hook:** in the docs theme client code, `if (typeof window !== 'undefined') (window as any).__EZ_DEMO_PEAK__ = () => busInstance?.peak() ?? 0` (guarded, SSR-safe).

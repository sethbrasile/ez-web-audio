**`ensureLoaded()` — lazy init (CLAUDE.md rule, no Load button):**
```typescript
async function ensureLoaded() {
  if (lib) return
  lib = await import('ez-web-audio')
  const { createDelay, createReverb, createCompressor, createEQ } = lib
  delay = createDelay({ time: 0.3, feedback: 0.4, mix: 0.5 })
  reverb = createReverb({ decay: 1.5, damping: 0.3 })
  reverb.mix = 0.4
  compressor = createCompressor({ threshold: -24, ratio: 4 })
  eq = createEQ({ low: 0, mid: 0, high: 0 })
}
```

**`togglePlay()`:** Calls ensureLoaded(), creates/starts oscillator source if not playing, stops if playing.

**`switchSource(type)`:**
1. Stop and null currentSource
2. Call ensureLoaded()
3. Create oscillator (freq 220, type 'sawtooth', gain 0.3) or track ('/ez-web-audio/audio/short-music.mp3', gain 0.8)
4. Check if Track has a `loop` property — set `currentSource.loop = true` if so
5. Re-attach existing effects: `currentSource.addEffects(chainOrder.map(e => e.effect))`
6. Call `currentSource.play()`

**`toggleBypass(entry)`:**
```typescript
function toggleBypass(entry: ChainEntry) {
  entry.effect.bypass = !entry.effect.bypass
  entry.bypassed = !entry.bypassed
}
```
DO NOT call removeEffect/addEffect on bypass — only the bypass setter.

**`moveEffect(index, direction)`:**
```typescript
function moveEffect(index: number, direction: 'up' | 'down') {
  if (!currentSource) return
  const newOrder = [...chainOrder.value]
  const swapIdx = direction === 'up' ? index - 1 : index + 1
  if (swapIdx < 0 || swapIdx >= newOrder.length) return
  ;[newOrder[index], newOrder[swapIdx]] = [newOrder[swapIdx], newOrder[index]]
  chainOrder.value = newOrder
  // Remove all then re-add in new order (single atomic rewire)
  for (const entry of chainOrder.value) {
    currentSource.removeEffect(entry.effect)
  }
  currentSource.addEffects(chainOrder.value.map(e => e.effect))
}
```

**Computed `activeChain`:** `computed(() => chainOrder.value.filter(e => !e.bypassed))`

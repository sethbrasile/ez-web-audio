**SampledDrumKit.vue** (H-7): The `onUnmounted` cleanup calls `sampler.stop()` but `Sampler` has no `stop()` method (only `play()`, `playIn()`, `playAt()`). The try/catch silently swallows the error making it a no-op.

Fix: Replace the cleanup block. Instead of calling `.stop()`, just null out the sampler references. Sampler plays one-shot sounds that naturally complete — there's nothing to stop.

```typescript
onUnmounted(() => {
  kickSampler = null
  snareSampler = null
  hihatSampler = null
})
```

**DrumMachineVue.vue** (H-8): The BPM `watch` handler stops all tracks, waits 50ms via `setTimeout`, then restarts. This creates an audible gap. BeatTrack has `setTempo(bpm)` for seamless live tempo changes.

Fix: Replace the watch handler at line 166-174 with:

```typescript
watch(bpm, (val) => {
  if (playing.value && initialized) {
    tracks.value.forEach(t => t.beatTrack.setTempo(val))
  }
})
```

No stop/restart needed — `setTempo()` updates the tempo on the next scheduler tick.

**FilterDemo.vue** (M-16): Two places call `source.rewireEffects()` manually:

1. **Line 114** in the `watch(filterType)` handler: After removing old filter and adding new filter, calls `source.rewireEffects()`. Since Phase 19 (DX-01), `addEffect()` and `removeEffect()` trigger auto-rewire. Remove the explicit `source.rewireEffects()` call on line 114.

2. **Line 143** in the `watch(bypassed)` handler: After setting `filter.bypass = newBypassed`, calls `source.rewireEffects()`. Since Phase 19, toggling `effect.bypass` auto-rewires. Remove the `source.rewireEffects()` call.

The resulting watch handlers should be:

```typescript
watch(filterType, async (newType) => {
  if (!playing.value || !filter || !source)
    return

  try {
    source.removeEffect(filter)
    filter = lib.createFilterEffect(newType, {
      frequency: frequency.value,
      q: q.value,
      gain: filterGain.value,
    })
    filter.bypass = bypassed.value
    source.addEffect(filter)
  }
  catch (err) {
    error.value = err instanceof Error ? err.message : 'Error changing filter type'
  }
})

watch(bypassed, (newBypassed) => {
  if (filter) {
    filter.bypass = newBypassed
  }
})
```

Note: The `bypassed` watcher no longer needs the `source` guard since bypass auto-rewire is handled internally by the effect. Also remove the `&& source` guard since it's not needed.

<task type="auto">
  <name>Task 2: DrumMachine accessibility — secondary beat indicator, scroll affordance, loading state</name>
  <files>docs/.vitepress/theme/components/DrumMachine.vue</files>
  <action>
1. **Secondary visual indicator for active beats (WCAG 1.4.1):** Active beats currently use only color to indicate state. Add a secondary indicator — a filled circle or checkmark symbol that appears when `beat.active` is true. Inside the `.beat-cell` button template, after the beat number span, add a conditional span:

```html
<span v-if="beat.active" class="beat-active-indicator" aria-hidden="true">&#9679;</span>
```

Where `&#9679;` is a filled circle (bullet). Style it:
```css
.beat-active-indicator {
  font-size: 0.5rem;
  display: block;
  line-height: 1;
  margin-top: 1px;
}
```

Adjust the beat-cell layout to stack the number and indicator vertically (it already uses flexbox with `align-items: center; justify-content: center;` — add `flex-direction: column;`).

2. **Scroll affordance on mobile (M24):** The `.beat-grid` at 768px already has `overflow-x: auto`, but there's no visual cue. Add a scroll shadow gradient to indicate scrollable content. In the `@media (max-width: 768px)` block, update `.beat-grid`:

```css
.beat-grid {
  /* existing styles... */
  -webkit-overflow-scrolling: touch;
  scroll-snap-type: x mandatory;
}

.beat-grid::after {
  content: '';
  position: sticky;
  right: 0;
  min-width: 16px;
  background: linear-gradient(to left, var(--vp-c-bg-soft), transparent);
  pointer-events: none;
}
```

Actually, a simpler approach: add a subtle "scroll for more" text hint below the grid on mobile:
```html
<div class="scroll-hint">Swipe to see all beats &rarr;</div>
```
```css
.scroll-hint {
  display: none;
  font-size: 0.75rem;
  color: var(--vp-c-text-3);
  text-align: right;
  margin-top: 0.25rem;
}
@media (max-width: 768px) {
  .scroll-hint { display: block; }
}
```

Place the scroll-hint inside each `.track-row`, after the `.beat-grid` div. Or, better: place a single hint at the bottom of `.sequencer`.

3. **Loading state on first play (L35):** Add a `loading` ref that is `true` while audio is initializing. Show a loading indicator on the play button:

In `<script setup>`:
```typescript
const loading = ref(false)
```

In the `togglePlay` or `init` function, set `loading.value = true` before `await init()` and `loading.value = false` after.

In the template, update the play button:
```html
<button class="play-btn" :disabled="loading" @click="togglePlay">
  {{ loading ? 'Loading...' : (playing ? 'Stop' : 'Play') }}
</button>
```

Add a disabled style:
```css
.play-btn:disabled {
  opacity: 0.6;
  cursor: wait;
}
```

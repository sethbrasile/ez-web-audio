  <behavior>
    Standalone function that crossfades between two Tracks using equal-power curves.

    **API:**
    ```typescript
    crossfade(fromTrack: Track, toTrack: Track, duration: number): Promise<void>
    ```

    **Equal-power curve (CONTEXT.md: "only correct choice"):**
    - Fade-out: cos(x) where x goes from 0 to PI/2 (1 -> 0)
    - Fade-in: sin(x) where x goes from 0 to PI/2 (0 -> 1)
    - Maintains constant power: cos^2(x) + sin^2(x) = 1
    - Use Float32Array with 256 samples (standard resolution)

    **Behavior (from CONTEXT.md):**
    - Source track (fromTrack): fade gain from current to 0
    - Destination track (toTrack):
      - If already playing: fade gain from current to 1 (don't restart)
      - If not playing: start at 0, play(), fade to 1
    - After duration: auto-stop fromTrack, reset its gain to 1.0
    - Fire-and-forget: function returns Promise that resolves when fade completes

    **Implementation details:**
    - Use setValueAtTime + setValueCurveAtTime for smooth automation
    - Access gainNode.gain directly (public in BaseSound)
    - Use setTimeout for post-fade cleanup (not audioContext timing needed)
    - Reset fromTrack gain to 1.0 for future playback

    **Test cases:**
    - generateEqualPowerCurve('in', 256) produces 0->1 sin curve
    - generateEqualPowerCurve('out', 256) produces 1->0 cos curve
    - Curve values at midpoint (128): both ~0.707 (sqrt(0.5))
    - crossfade starts destination track if not playing
    - crossfade doesn't restart destination if already playing
    - crossfade fades out source track
    - crossfade fades in destination track
    - crossfade stops source after duration
    - crossfade resets source gain to 1.0 after stop
    - crossfade works with different durations (1s, 5s)
  </behavior>

       ```typescript
       function generateEqualPowerCurve(
         direction: 'in' | 'out',
         length: number
       ): Float32Array {
         const curve = new Float32Array(length)
         for (let i = 0; i < length; i++) {
           const percent = i / (length - 1)
           const angle = percent * 0.5 * Math.PI  // 0 to PI/2
           curve[i] = direction === 'in'
             ? Math.sin(angle)   // 0 -> 1
             : Math.cos(angle)   // 1 -> 0
         }
         return curve
       }
       ```

    3. **GREEN: Implement crossfade function**
       ```typescript
       async function crossfade(
         fromTrack: Track,
         toTrack: Track,
         duration: number
       ): Promise<void> {
         const isToTrackPlaying = toTrack.isPlaying
         const audioContext = fromTrack.audioContext
         const startTime = audioContext.currentTime

         const curveLength = 256
         const fadeOutCurve = generateEqualPowerCurve('out', curveLength)
         const fadeInCurve = generateEqualPowerCurve('in', curveLength)

         // Fade out source
         const fromGain = fromTrack.gainNode.gain
         fromGain.setValueAtTime(fromGain.value, startTime)
         fromGain.setValueCurveAtTime(fadeOutCurve, startTime, duration)

         // Fade in destination
         const toGain = toTrack.gainNode.gain
         if (isToTrackPlaying) {
           toGain.setValueAtTime(toGain.value, startTime)
         } else {
           toGain.setValueAtTime(0, startTime)
           await toTrack.play()
         }
         toGain.setValueCurveAtTime(fadeInCurve, startTime, duration)

         // Return promise that resolves after fade, handles cleanup
         return new Promise((resolve) => {
           setTimeout(async () => {
             await fromTrack.stop()
             fromGain.setValueAtTime(1.0, audioContext.currentTime)
             resolve()
           }, duration * 1000)
         })
       }
       ```

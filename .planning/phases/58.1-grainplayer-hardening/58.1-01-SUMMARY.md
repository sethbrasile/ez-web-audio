# Summary: 58.1-01 GrainPlayer Hardening

## What Was Done

Three QC findings fixed in GrainPlayer:

1. **QC-1-03 (high) — Overlap clamping**: The `overlap` setter now clamps to `[0, grainSize - 0.001]`, preventing the hop size from dropping below 0.001s (max ~1000 grains/sec). The `grainSize` setter also re-clamps overlap when shrinking. Constructor applies the same clamping.

2. **QC-1-11 (medium) — WorkerTimer migration**: Replaced `setTimeout`-based scheduling loop with `WorkerTimer` (already used by Transport and BeatTrack). WorkerTimer uses an inline Blob Worker immune to browser background-tab throttling, with setTimeout fallback for test environments.

3. **QC-1-25 (medium) — Dead code removal**: Removed unreachable `if (this._loop && offset > maxOffset)` block in `scheduleGrain()` — offset was already clamped to maxOffset on the previous line.

## Key Changes

- `src/grain-player.ts`: Import WorkerTimer, replace timerId with WorkerTimer instance, clamp overlap in setter/constructor/grainSize setter, remove dead loop-offset code
- `src/grain-player.test.ts`: 4 new overlap clamping tests, updated timer-related test

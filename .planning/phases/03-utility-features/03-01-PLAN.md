Create standalone collection utility functions with these specifications:

1. **stopAll(sounds: (Playable | Playable[])[]): Promise<void>**
   - Flatten nested arrays using `Array.flat(Infinity)`
   - Call `stop()` on each Playable using `Promise.allSettled`
   - Collect errors and throw aggregate error if any failed
   - Error message: `Failed to stop ${errors.length} of ${total} sounds`

2. **pauseAll(tracks: (Track | Track[])[]): Promise<void>**
   - Flatten nested arrays using `Array.flat(Infinity)`
   - Type guard: check `'pause' in item && typeof item.pause === 'function'`
   - Skip items without pause method (only Track has pause)
   - Use Promise.allSettled for best-effort behavior
   - Error message: `Failed to pause ${errors.length} of ${total} tracks`

3. **playAll(sounds: (Playable | Playable[])[]): Promise<void>**
   - Same pattern as stopAll
   - Call `play()` on each Playable
   - Error message: `Failed to play ${errors.length} of ${total} sounds`

Import Track and Playable types. Export all three functions as named exports.

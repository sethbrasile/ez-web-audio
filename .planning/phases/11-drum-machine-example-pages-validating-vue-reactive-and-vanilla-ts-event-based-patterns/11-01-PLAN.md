# Drum Machine: Vue Reactive Pattern

<script setup>
import DrumMachineVue from '../.vitepress/theme/components/DrumMachineVue.vue'
</script>

Brief intro: This page demonstrates using Vue's `reactive()` with BeatTrack's `wrapWith` option. Beat properties auto-toggle and trigger re-renders — no event listeners needed for visual sync.

<DrumMachineVue />

## How It Works

Explain the reactive property pattern:
1. `wrapWith: (beat) => reactive(beat)` wraps each Beat in a Vue reactive proxy
2. Beat.currentTimeIsPlaying auto-toggles true/false on the scheduler's timeline
3. Vue detects the property change and re-renders the bound CSS class
4. No `.on('beat', ...)` event listener needed — the Beat IS the state

## Key Code

Show the essential setup code:
```typescript
const kick = await createBeatTrack([...urls], {
  numBeats: 16,
  wrapWith: (beat) => reactive(beat)
})
```

Show the template binding:
```vue
<button
  v-for="(beat, i) in track.beats"
  @click="beat.active = !beat.active"
  :class="{ active: beat.active, current: beat.currentTimeIsPlaying }"
/>
```

## Mute & Solo

Explain the mute/solo implementation pattern — storing active states, toggling beats.

## Why This Works

Explain the WeakMap→instance property refactor that made this possible. Previously, Beat objects were cached in a module-level WeakMap, which broke when Vue's reactive() wrapped the instance (proxy !== original object as Map key). Now beats use a private instance property `_beats`, so reactive proxies work correctly.

## When to Use This Pattern

- Vue 3 with `reactive()`
- Solid.js with `createMutable()`
- Any framework with reactive proxies that can wrap plain objects

## See Also

Link to vanilla TS page: [Event-Based Pattern](/examples/drum-machine-vanilla) — for React, vanilla JS, or any framework without reactive proxies.
```

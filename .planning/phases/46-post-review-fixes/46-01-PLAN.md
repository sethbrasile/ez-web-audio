<objective>
Fix `.d.ts` extension-less imports that break `moduleResolution: "nodenext"` consumers by enabling `rollupTypes: true` in vite-plugin-dts.

Purpose: The current build emits per-file `.d.ts` files with extension-less imports (e.g., `from './utils/create-time-object'` instead of `from './utils/create-time-object.js'`). This causes 30+ TS2835 errors for any consumer using `moduleResolution: "nodenext"` or `"node16"`. Bundling all declarations into a single file eliminates cross-file imports entirely.

Output: Updated vite.config.js, verified bundled dist/index.d.ts
</objective>

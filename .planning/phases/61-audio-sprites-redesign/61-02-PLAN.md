    **2. Demo first** (above the fold):
    - Import and render `<AudioSpriteDemo />`
    - Brief intro sentence: "Audio sprites bundle multiple short sounds into one file, reducing HTTP requests. Click below to hear how it works."

    **3. "What just happened?" section:**
    - Explain that all 6 sounds were packed into a single MP3 file
    - The manifest maps names to time regions within that file
    - `createSprite()` loads the file once, then plays segments by name
    - Why this matters: fewer HTTP requests, faster loading for games/apps with many SFX

    **4. "Sprite Formats" section:**
    - Document both formats side by side:

    **audiosprite format** (`spritemap` key, seconds):
    ```json
    {
      "spritemap": {
        "laser": { "start": 0, "end": 0.3, "loop": false }
      }
    }
    ```

    **Howler.js format** (`sprite` key, millisecond tuples):
    ```json
    {
      "sprite": {
        "laser": [0, 300],
        "explosion": [1000, 2500],
        "powerup": [4000, 500, true]
      }
    }
    ```

    - Note: format detection is automatic. EZ Web Audio detects which format you're using and normalizes internally.
    - Note: Howler tuples are `[offset_ms, duration_ms]` with optional third boolean for loop.

    **5. "Basic Usage" section:**
    ```typescript
    import { createSprite } from 'ez-web-audio'

    // audiosprite format
    const sprite = await createSprite('sounds.mp3', {
      spritemap: {
        laser: { start: 0, end: 0.3 },
        explosion: { start: 1.0, end: 2.5 }
      }
    })

    // Or Howler format — works the same way
    const sprite2 = await createSprite('sounds.mp3', {
      sprite: {
        laser: [0, 300],
        explosion: [1000, 2500]
      }
    })

    sprite.play('laser')
    sprite.play('explosion', { gain: 0.7 })
    ```

    **6. "Looping & Stopping" section:**
    - Show loop: true usage
    - Show stop(name) and stopAll()

    **7. "Creating Sprites" section:**
    - Mention [audiosprite CLI](https://github.com/tonistiigi/audiosprite) for automated sprite generation
    - Link to [soundfx](https://github.com/rse/soundfx) as a ready-made collection of CC-licensed sounds
    - Brief note about silence gaps between sounds (200ms recommended)

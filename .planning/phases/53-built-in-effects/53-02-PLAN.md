# Plan 53-02: Distortion + Compressor Effects

## Objective

Build two effects that use single native Web Audio nodes: DistortionEffect (WaveShaperNode with curve generation and tone control) and CompressorEffect (DynamicsCompressorNode with 1:1 parameter mapping).

**Note:** This plan depends on BaseEffect from Plan 53-01 at the code level, but since the file is small and well-defined, the executor can read it as context. Wave assignment accounts for this — if BaseEffect isn't ready, wait.

## Context

@src/effects/base-effect.ts (BaseEffect to extend — created by Plan 53-01)
@src/effects/filter-effect.ts (pattern reference for getters/setters)
@src/effects/index.ts (exports to update)
@src/audio-context.ts (getOrCreateAudioContext)
@CLAUDE.md (project conventions)

## must_haves

- DistortionEffect with selectable curve types (soft, hard, fuzz, overdrive, custom)
- Built-in tone control on distortion (post-WaveShaper lowpass filter)
- CompressorEffect with threshold, ratio, knee, attack, release
- CompressorEffect.reduction getter for metering
- Both effects work with addEffect() on any sound type
- Both use context-free factory pattern

  <behavior>
    - createDistortion() with no args creates distortion with defaults (type: 'soft', amount: 50, tone: 0.5, oversample: '4x')
    - createDistortion({ type: 'hard', amount: 80 }) uses specified curve
    - createDistortion({ type: 'fuzz' }) creates fuzz curve

    - createDistortion({ type: 'custom', curve: float32Array }) uses provided curve directly
    - dist.amount getter/setter regenerates the curve when changed
    - dist.amount is clamped to 0-100
    - dist.type getter returns current type; setter regenerates curve
    - dist.tone getter/setter controls post-distortion lowpass (0 = dark/200Hz, 1 = bright/8000Hz)
    - dist.tone is clamped to 0-1
    - dist.oversample getter/setter ('none' | '2x' | '4x')
    - dist.bypass and dist.mix work (inherited from BaseEffect)
    - dist.rampTo('tone', 0.8, 1) schedules smooth tone ramp
    - createDistortion(audioContext, opts) overload works
    - WaveShaperNode curve has 44100 samples
  </behavior>
  <action>
    Create `src/effects/distortion-effect.ts`:

    1. Types:
       - `DistortionType = 'soft' | 'hard' | 'fuzz' | 'overdrive' | 'custom'`
       - `DistortionOptions`: `type?: DistortionType`, `amount?: number` (0-100, default 50), `tone?: number` (0-1, default 0.5), `oversample?: OversampleType` (default '4x'), `curve?: Float32Array` (for custom type), `mix?: number`

    2. Private `generateCurve(type, amount)` function:
       - 44100 samples
       - `soft`: `Math.tanh(k * x)` where k = amount / 10
       - `hard`: `Math.max(-1, Math.min(1, k * x))` where k = amount / 25
       - `fuzz`: `((3 + k) * x * 20 * (Math.PI / 180)) / (Math.PI + k * Math.abs(x))` where k = amount * 2
       - `overdrive`: asymmetric — negative: `-Math.tanh(-x * k * 0.5)`, positive: `Math.tanh(x * k)` where k = amount / 10

    3. `DistortionEffect` extending `BaseEffect`:
       - WaveShaperNode for distortion
       - BiquadFilterNode (lowpass) for tone control
       - Signal chain: inputNode -> waveShaperNode -> toneFilter -> wetGain
       - Tone maps 0-1 to frequency range 200-8000 Hz (exponential: `200 * Math.pow(40, tone)`)
       - Getters/setters for `amount`, `type`, `tone`, `oversample`
       - `amount` setter regenerates curve (unless type is 'custom')
       - `type` setter regenerates curve (unless switching to 'custom' without providing curve)

    4. `getAudioParam()`: map 'tone' -> toneFilter.frequency

    5. `createDistortion()` factory with context-free overloads
  </action>

    <automated>pnpm test src/effects/distortion-effect.test.ts</automated>
  </verify>
  <done>DistortionEffect works with all 4 built-in curve types + custom, tone control shapes output, oversample prevents aliasing.</done>

  <action>
Step 1 — Remove unused dependencies:
```bash
pnpm remove @dotenvx/dotenvx concurrently
```
Both are confirmed unused: @dotenvx/dotenvx is not referenced in any npm scripts or source files. concurrently is not referenced in any npm scripts.

Step 2 — Upgrade vite, vitest, and happy-dom together:
```bash
pnpm add -D vite@latest vitest@latest happy-dom@latest
```
These must be upgraded together because vitest 4.x requires vite 6+.

Step 3 — Check vite.config.js for breaking changes:
- The `/// <reference types="vitest" />` triple-slash directive at the top of vite.config.js was the vitest 1.x way to add test config. In vitest 2+, the `test` block in vite config is still supported but the triple-slash reference may cause type errors. If TypeScript complains, remove the triple-slash directive line.
- Vite 7 drops the `__dirname` usage in ESM. If build errors mention __dirname, replace `resolve(__dirname, 'src/index.ts')` with `resolve(import.meta.dirname, 'src/index.ts')` (Node 20.11+ supports import.meta.dirname) or use `fileURLToPath(new URL('./src/index.ts', import.meta.url))`.
- Check if `vite-plugin-dts` and `vite-tsconfig-paths` still work with vite 7. If not, upgrade them too: `pnpm add -D vite-plugin-dts@latest vite-tsconfig-paths@latest`.

Step 4 — Also upgrade vite-plugin-dts and vite-tsconfig-paths to their latest versions since they depend on vite:
```bash
pnpm add -D vite-plugin-dts@latest vite-tsconfig-paths@latest
```

Step 5 — Run the full test suite:
```bash
pnpm test -- --run
```
If tests fail, triage:
- If failures are in happy-dom DOM API differences: adjust test assertions to match new happy-dom behavior.
- If failures are vitest config issues: check vite.config.js test block for deprecated options.

Step 6 — Run the library build:
```bash
pnpm build:lib
```
If build fails, fix vite.config.js per the notes in Step 3.

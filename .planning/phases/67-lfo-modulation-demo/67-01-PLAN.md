- Refs: `initialized`, `playing`, `loading`, `error`, `activeTab` (tremolo|vibrato|filter), `rateSlider` (0-100), `depthSlider` (0-100), `waveformType` (sine|square|sawtooth|triangle)

- Computed `depth`: depthSlider / 100 (0-1.0 ratio)

- `ensureLoaded()`: Lazy init pattern -- dynamic import of ez-web-audio on first call. Set `initialized = true`.

- `play()`:
  1. Call `ensureLoaded()`
  2. Create oscillator: `lib.createOscillator({ frequency: 330, type: 'sawtooth' })`, set gain to 0.3
  3. Create filter: `lib.createFilterEffect('lowpass', { frequency: 1500, q: 2 })` -- store but don't attach yet
  4. Create LFO: `lib.createLFO({ frequency: rate.value, depth: computeDepthForTab(), type: waveformType.value })`
  5. Connect LFO based on activeTab (call `connectLFOToTab()`)
  6. Start LFO, play oscillator
  7. Set `playing = true`, start canvas animation

- `stop()`: Stop oscillator, stop LFO, cancel animation frame, null out audio objects, `playing = false`

- `connectLFOToTab()`:
  - Disconnect LFO from current target
  - If tremolo: `lfo.connect(oscillator, 'gain')` -- depth is ratio (0-1)
  - If vibrato: `lfo.connect(oscillator, 'frequency')` -- depth is cents, map 0-1 to 0-100 cents
  - If filter: ensure filter attached via `oscillator.addEffect(filter)` (set filterAttached flag), then `lfo.connect(filter, 'frequency', { depthUnit: 'absolute' })` -- depth maps 0-1 to 0-2000 Hz

- `computeDepthForTab()`: Convert normalized 0-1 depth to the right unit for active tab:
  - tremolo: depth * 0.5 (max 50% gain wobble to avoid silence)
  - vibrato: depth * 100 (max 100 cents = 1 semitone)
  - filter: depth * 2000 (max 2000 Hz sweep range)

- Watch `activeTab`: Call `connectLFOToTab()` if playing. Update canvas accent color.
- Watch `rate`: Update `lfo.frequency` if playing
- Watch `depth` (the computed one): Update `lfo.depth = computeDepthForTab()` if playing
- Watch `waveformType`: Update `lfo.type` if playing

- `onUnmounted()`: Cancel animation frame, dispose LFO, stop oscillator, remove resize listener

# LFO Modulation

Explore Low Frequency Oscillator (LFO) modulation effects. An LFO generates a slow waveform that modulates an audio parameter -- creating effects like tremolo (volume wobble), vibrato (pitch wobble), and filter sweeps (tone color changes).

Try the presets to hear each effect, then adjust the rate, depth, and waveform shape to explore how LFO parameters affect the sound.

<script setup>
import LFODemo from '../.vitepress/theme/components/LFODemo.vue'
</script>

<LFODemo />

## How It Works

- **Tremolo** modulates the oscillator's gain (volume), creating a pulsing effect
- **Vibrato** modulates the oscillator's frequency (pitch), creating a wobbling effect
- **Filter Sweep** modulates a lowpass filter's cutoff frequency, creating a wah-like tone sweep

### Code Example

```typescript
import { createOscillator, createLFO } from 'ez-web-audio'

const oscillator = await createOscillator({ frequency: 330, type: 'sawtooth' })

// Create an LFO at 5 Hz with sine wave
const lfo = createLFO({ frequency: 5, depth: 0.3, type: 'sine' })

// Connect to gain for tremolo effect
lfo.connect(oscillator, 'gain')

lfo.start()
oscillator.play()
```

## Global Constraints (copy into the brief verbatim as "Hard Constraints")

- Components render inside the VitePress default theme content column (~688px max width); must degrade gracefully to 320px.
- Light AND dark mode via VitePress CSS custom properties (`--vp-c-*` family); canvas visualizations read colors from CSS vars at draw time — no hardcoded hex.
- Implementable as Vue 3 SFCs with scoped styles; **no new runtime dependencies** (no component libraries, no icon fonts; inline SVG fine).
- WCAG 2.1 AA: contrast, focus-visible states, keyboard operability, ARIA on custom controls; touch targets ≥44×44px.
- Demos must render fully visible immediately — no load/init buttons; first interaction starts audio.
- Volume-safety messaging pattern must exist (current demos have 3 inconsistent styles — design ONE).

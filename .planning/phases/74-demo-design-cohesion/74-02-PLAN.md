# 74-02: Implement the claude-design Handoff Packet

> **For agentic workers:** Execute per `.planning/M8-PLAYBOOK.md`. **Blocked on:** human gate 1 return (`.planning/DESIGN-HANDOFF/` exists) AND Phase 73 complete. This is a *runtime-expanded* plan: the concrete task list depends on packet contents, so the orchestrator authors the task breakdown as its first task, following the rules here.

**Goal:** All docs demos implement the claude-design specs — shared kit extracted, visual cohesion achieved, AA verified — without changing demo behavior or audio logic.

## Global Constraints

- Everything in 74-01's Hard Constraints (VitePress vars, 320px–688px, AA, ≥44px touch, no new runtime deps, no load buttons).
- Audio logic untouched — this phase is presentation only. If a design requires a behavior change (e.g., a control the demo lacks), log to `M8-QUESTIONS.md` and implement the closest presentation-only version.
- Packet conflicts with a Hard Constraint → constraint wins; log the deviation.
- E2E: selector updates allowed; assertion/behavior changes require SUMMARY sign-off note.

---

### Task 0: Expand the packet into a task list

- [ ] Read the full packet. Write `74-02-TASKS.md` in this phase directory:
  1. **Shared kit first.** One task per shared component the packet specifies (e.g. DemoCard, ParameterSlider, PlayButton, VolumeWarning — use the packet's names). Each: create `docs/.vitepress/theme/components/kit/<Name>.vue` + a usage note. Props typed; slots over config where sensible; styles scoped, tokens from VitePress vars per packet mapping.
  2. **Then one task per demo** applying the packet spec to that demo using the kit.
  3. **Last: IA suggestions triage** — list the packet's advisory IA suggestions with a recommendation each (adopt / skip / needs-Seth). Only adopt items that are pure config changes (sidebar grouping, page ordering, retitling). Anything structural → `M8-QUESTIONS.md`.
- [ ] Commit the task list, then execute it task-by-task under the normal dispatch protocol.

### Per-task rules (every kit and demo task)

- [ ] Verification per task: `pnpm typecheck && pnpm lint && pnpm test:e2e`, plus a manual render check via `pnpm dev` + Playwright screenshot of the demo page in BOTH color schemes (`page.emulateMedia({ colorScheme: 'dark' })`) saved to the phase directory for the human gates.
- [ ] A11y check per demo: keyboard-only operation of every control; `aria-label` presence on icon-only buttons; focus-visible ring visible in both schemes.
- [ ] Commit per task — `feat(74-02): <component> per design packet`.

### Exit

- [ ] All demos match packet (screenshot set complete, light+dark).
- [ ] Kit components documented in `docs/.vitepress/theme/components/kit/README.md`.
- [ ] Playbook exit gate → `74-02-SUMMARY.md` (deviations, IA adoptions, questions filed) → STATE/ROADMAP.

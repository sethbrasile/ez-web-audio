**M-5 — onPlaySet deduplication:**
In the `onPlaySet()` method, before pushing to `startingValues`, filter out any existing entries for the same `type`. The deduplication should only remove entries from `startingValues` (the initial set-value array), NOT from `valuesAtTime`, `exponentialValues`, or `linearValues` — because `onPlayRamp` internally uses `onPlaySet` twice to build a ramp pair, and removing from those arrays would break ramp pairs.

Read the research Open Question #2 carefully. The simplest correct approach:
- In the `to()` callback of `onPlaySet`, filter `startingValues` to remove prior entries for the same `type` before pushing the new one.
- The `at()` and `endingAt()` callbacks already call `removeStartingValue()` which handles the transition from startingValues to timed arrays.
- Do NOT filter `valuesAtTime`/`exponentialValues`/`linearValues` — these are managed by the `at()`/`endingAt()` callbacks and clearing them would break `onPlayRamp()`.

```typescript
// In onPlaySet().to():
this.startingValues = this.startingValues.filter(v => v.type !== type)
const paramValue: ParamValue = { type, value }
this.startingValues.push(paramValue)
```

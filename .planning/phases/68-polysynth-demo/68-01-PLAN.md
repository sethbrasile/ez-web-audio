**Audio logic -- CRITICAL patterns from research:**

1. **Lazy init with ensureLoaded():**
```typescript
let lib: typeof import('ez-web-audio') | null = null
let synth: PolySynth | null = null
async function ensureLoaded() {
  if (!lib) lib = await import('ez-web-audio')
}
```

2. **PolySynth recreation on immutable param change:**
`maxVoices` and `stealStrategy` are `private readonly` -- changing either requires dispose + recreate. ALSO: envelope and waveform type are baked into the voice factory at construction, so changing ADSR or waveform also requires recreation.

Use a dirty flag pattern: when ADSR/waveform changes, set `synthDirty = true`. Recreate on next noteOn (not immediately, to avoid stopping playing notes). For maxVoices/stealStrategy changes, recreate immediately via `watch()` since those are structural changes per user decision ("reducing max voices below current active count immediately steals excess voices").

```typescript
const synthDirty = ref(false)
watch([waveType, envelope], () => { synthDirty.value = true }, { deep: true })
watch([maxVoices, stealStrategy], () => { if (synth) recreateSynth() })
```

3. **Voice handle tracking:**
```typescript
const voiceHandles = new Map<string, VoiceHandle>()
```
On noteOn: `const handle = synth.play({ frequency }); voiceHandles.set(note, handle); activeNotes.value.add(note)`
On noteOff: `handle.stop(); voiceHandles.delete(note); activeNotes.value.delete(note)`
On recreate: clear both maps.

4. **Voice count polling via requestAnimationFrame:**
Poll `synth.activeVoices` via rAF for smooth fill bar updates. Start on mount, cancel on unmount.

5. **voicestolen event handler:**
```typescript
synth.on('voicestolen', handleVoiceStolen)
function handleVoiceStolen() {
  stealMessage.value = `Voice stolen (${currentStrategyLabel})`
  // clear previous timeout, set new 1.2s fade timeout
}
```

6. **Cleanup on unmount:**
```typescript
onUnmounted(() => {
  if (synth) { synth.stopAll(); synth.dispose() }
  if (rafId) cancelAnimationFrame(rafId)
})
```

## How It Works

The [`PolySynth`](/guide/poly-synth) manages a pool of oscillator voices. When you play more notes than the maximum voice count, it uses the selected **steal strategy** to decide which voice to replace:

- **Oldest (LRU)** -- replaces the least recently used voice
- **Oldest Active** -- replaces the voice that has been playing the longest
- **Quietest** -- replaces the voice with the lowest current gain

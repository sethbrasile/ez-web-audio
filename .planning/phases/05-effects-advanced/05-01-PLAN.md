  <name>Task 3: Create EffectWrapper for external effect compatibility</name>
  <files>src/effects/effect-wrapper.ts, src/effects/effect-wrapper.test.ts, src/effects/index.ts</files>
  <action>
Create EffectWrapper to wrap external effects (Tuna.js, custom WaveShaperNode, etc.):

1. **src/effects/effect-wrapper.ts**:
- ExternalEffect interface: `{ connect(destination: AudioNode): void }` (minimal requirement)
- EffectWrapper class implements Effect
- Constructor takes AudioContext and the external effect object
- Creates wet/dry mixing infrastructure:
  - input: GainNode (receives signal from chain)
  - output: GainNode (sends to next in chain)
  - dryGain: GainNode (dry path gain)
  - wetGain: GainNode (wet path gain)
- Routing:
  - Dry path: input -> dryGain -> output
  - Wet path: input -> externalEffect -> wetGain -> output
  - Call externalEffect.connect(wetGain) to complete wet path
- `bypass` getter/setter: when true, wetGain=0, dryGain=1
- `mix` getter/setter: equal-power crossfade between wet and dry
- `effect` getter: returns the wrapped external effect (for accessing its properties)

2. **Factory function** `wrapEffect(audioContext, externalEffect)`:
- Returns new EffectWrapper instance
- Use for effects that only have connect() method

3. **Update src/effects/index.ts**:

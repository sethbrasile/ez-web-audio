# Plan 57.1-01 Summary: PolySynth Core Fixes

## Status: COMPLETE

## What was done

Fixed three PolySynth bugs (QC-1-01, QC-1-09, QC-1-21):

1. **Voice state machine (QC-1-01)**: Separated stop and end event handlers so voices transition active -> released (on stop) -> available (on end). Previously both transitions happened on the same event, making `released` state unreachable.

2. **Listener cleanup (QC-1-09)**: Added `onStop` and `onEnd` references to VoiceEntry. `cleanupVoiceListeners()` removes old listeners before re-registration in `setupVoiceListeners()`. Prevents orphaned listeners on voice stealing and reactivation.

3. **activeVoices performance (QC-1-21)**: Replaced `this.voices.filter(v => v.state === 'active').length` with an incrementally maintained `_activeCount` field. Counter is incremented on activation and decremented on release/steal/stop.

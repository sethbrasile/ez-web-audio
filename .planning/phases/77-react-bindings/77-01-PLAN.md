# 77-01: @ez-web-audio/react Hooks

> **For agentic workers:** Execute per `.planning/M8-PLAYBOOK.md`. Depends only on Phase 72 — may run parallel to 74/75/76. TDD throughout.

**Goal:** `@ez-web-audio/react`: hooks mirroring the Vue composables 1:1 (same uniform shape, same names), SSR-safe, plus StackBlitz-embedded examples and a rewritten React integration guide.

**Architecture:** Same generic-factory design as 72-02: one `createFactoryHook` produces all wrappers; `useCleanup` disposes on unmount via `useEffect`. Read `packages/vue/src/` first — the React package mirrors its structure file-for-file where sensible. Parity is a stated feature: a developer switching frameworks re-learns nothing.

## Global Constraints

- Runtime deps: none. Peers: `ez-web-audio`, `react >=18`.
- Uniform shape (mirror of Vue, exact): `{ instance: T | null, loading: boolean, error: Error | null, load(...args): Promise<T> }` — plain values, not refs; re-render via state.
- No AudioContext until `load()`/`init()`. Must be safe under React StrictMode double-invocation (load idempotence) and SSR (no window access at module scope).
- Hook inventory must match the Vue package's final inventory (see `72-02-SUMMARY.md`): `useSound`, `useTrack`, `useOscillator`, `useSampler`, `usePolySynth`, `useGrainPlayer`, `useLFO`, `useTransport`, `useBeatTrack` (without the Vue-reactive wrapWith — document the difference), `useAudioContext`, `useCleanup`.

- [ ] **Step 2: FAIL.** **Step 3: Implement:**

```ts
import { useCallback, useEffect, useRef, useState } from 'react'

export interface UseFactoryReturn<T, A extends unknown[]> {
  instance: T | null
  loading: boolean
  error: Error | null
  load: (...args: A) => Promise<T>
}

export function createFactoryHook<T, A extends unknown[]>(
  factory: (...args: A) => Promise<T>,
) {
  return function useFactory(): UseFactoryReturn<T, A> {
    const [instance, setInstance] = useState<T | null>(null)
    const [loading, setLoading] = useState(false)
    const [error, setError] = useState<Error | null>(null)
    const pending = useRef<Promise<T> | null>(null)
    const created = useRef<T | null>(null)
    const mounted = useRef(true)
    useEffect(() => { mounted.current = true; return () => { mounted.current = false } }, [])

    const load = useCallback((...args: A): Promise<T> => {
      if (created.current) return Promise.resolve(created.current)
      if (pending.current) return pending.current
      if (mounted.current) { setLoading(true); setError(null) }
      pending.current = factory(...args)
        .then((c) => { created.current = c; if (mounted.current) setInstance(c); return c })
        .catch((e) => {
          const err = e instanceof Error ? e : new Error(String(e))
          if (mounted.current) setError(err)
          throw err
        })
        .finally(() => { if (mounted.current) setLoading(false); pending.current = null })
      return pending.current
    }, [])

    return { instance, loading, error, load }
  }
}
```

  <action>
1. Create `scripts/patch-llms-size.mjs` (Node.js, ESM):
   - Import `readFileSync`, `writeFileSync`, `statSync`, `readdirSync` from `node:fs`
   - Import `join` from `node:path`
   - Set `distDir = 'docs/.vitepress/dist'`
   - Read `llms-full.txt` from dist, get file size via `statSync`, compute `Math.round(stats.size / 1024)` KB
   - Define recursive `walkDir(dir, callback)` function
   - Walk dist, for each `.html` or `.txt` file, read content, if it contains `__LLMS_FULL_SIZE__`, replace all occurrences with `${sizeKB} KB` and write back
   - Log: `Patched llms-full.txt size: ${sizeKB} KB`
   - Handle missing file gracefully: if `llms-full.txt` doesn't exist, log warning and exit 0 (don't break CI)

2. Update `package.json` `docs:build` script:
   - Change from: `"typedoc && vitepress build docs"`
   - Change to: `"typedoc && vitepress build docs && node scripts/patch-llms-size.mjs"`

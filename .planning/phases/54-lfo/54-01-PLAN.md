## Design Decisions (Claude's Discretion — Resolved)

These decisions are resolved here for the executor. Follow them exactly.

### Ownership Model: LFO-Driven (Push)
LFO owns all connection records. BaseSound does NOT need a registry of connected LFOs. The LFO patches `target.dispose()` at connect time to trigger cleanup. This keeps BaseSound surface area minimal.

### AudioContext Sourcing: Lazy from first connect()
`createLFO(options)` stores options only. First `lfo.connect()` call extracts audioContext from target and initializes the internal OscillatorNode graph. If `lfo.start()` is called before any `connect()`, throw: `"LFO has no AudioContext — call connect() first or pass audioContext to createLFO()"`.

### Per-target Depth: Ratio with cents override for frequency
- Gain, pan, detune: ratio-based depth (`absoluteDepth = paramValue * depth`). If paramValue is near zero (Math.abs < 0.001), use `depth` as absolute value directly (prevents zero-depth on center-pan).
- Frequency: cents-based depth by default (`absoluteDepth = freq * (2^(depthCents/1200) - 1)`). Default depth for frequency = 100 cents (one semitone).
- Allow override via `ConnectOptions.depthUnit: 'ratio' | 'cents' | 'absolute'`.

### Clamping: None
Web Audio natively clamps AudioParams to valid ranges. No explicit clamping in LFO.

### Presets: No presets
Document examples in docs page (Plan 02), not in the library.

### Phase Configurability: Not supported
OscillatorNode.start() does not accept phase offset. Not worth implementing via PeriodicWave hack.

### Dispose Behavior: Patch target.dispose()
LFO patches `target.dispose()` at connect time. The patched dispose calls `lfo._cleanupTarget(target)` before running the original dispose. Idempotent — multiple LFOs can patch the same target.

### S&H Implementation: Looping AudioBufferSourceNode
Sample-and-hold uses a 1-second looping AudioBufferSourceNode with stepped random values. Frequency changes require regenerating the buffer and restarting the source.

### Stop/Start Lifecycle
`stop()` stops the oscillator and marks `_isRunning = false` but keeps all connection registrations. `start()` recreates the OscillatorNode (single-use per spec), rewires to existing per-connection depth GainNodes, and starts. This allows stop/start cycling.

## must_haves

- LFO class with configurable frequency, depth, and waveform (sine, square, sawtooth, triangle, sample-and-hold, PeriodicWave)
- `lfo.connect(target, paramName, options?)` connects to any AudioParam on BaseSound or BaseEffect
- One LFO can connect to multiple targets simultaneously
- Depth as ratio with cents fallback for frequency; depthUnit override in ConnectOptions
- Frequency and depth changeable while running with smooth ramping
- syncToBPM(bpm, noteLength) sets frequency to match note rate
- syncLifecycle option ties LFO start/stop to sound play/stop events
- retrigger option resets LFO phase on sound play
- sound.dispose() auto-disconnects LFO via patched dispose
- lfo.dispose() disconnects all connections and stops oscillator
- getPannerNode() added to BaseSound
- getParam() added to BaseEffect

    Create `src/lfo.ts` with:

    **Types:**
    ```typescript
    export type LFOWaveform = 'sine' | 'square' | 'sawtooth' | 'triangle' | 'sample-and-hold'

    export interface LFOOptions {
      frequency?: number    // Hz, default 1
      depth?: number        // ratio (0-1 for most), default 0.3
      type?: LFOWaveform | PeriodicWave  // default 'sine'
    }

    export interface LFOConnectOptions {
      syncLifecycle?: boolean   // default false
      retrigger?: boolean       // default false
      depthUnit?: 'ratio' | 'cents' | 'absolute'  // default: 'ratio' for most, 'cents' for 'frequency'
      depth?: number            // per-connection depth override (overrides LFO-level depth)
    }
    ```

    **Internal types:**
    ```typescript
    interface ConnectionRecord {
      audioParam: AudioParam
      depthGain: GainNode          // per-connection depth scaler
      target: BaseSound | BaseEffect
      paramName: string
      options: LFOConnectOptions
      playListener?: (e: Event) => void
      stopListener?: (e: Event) => void
      endListener?: (e: Event) => void
    }
    ```

    **LFO class:**

    Private state:
    - `_options: Required<{ frequency: number; depth: number }>` (parsed from constructor)
    - `_type: LFOWaveform | PeriodicWave`
    - `_oscillatorNode: OscillatorNode | AudioBufferSourceNode | null`
    - `_audioContext: AudioContext | null`
    - `_isRunning: boolean`
    - `_connections: ConnectionRecord[]`
    - `_disposePatchMap: Map<BaseSound | BaseEffect, () => void>` (original dispose references)
    - `_disposed: boolean`

    **Key methods:**

    `connect(target, paramName, options?)`:
    1. If `_audioContext` is null, extract from target (BaseSound has `.audioContext`, BaseEffect has protected `.audioContext` — access via `(target as any).audioContext`)
    2. If oscillator not yet created, call `_initNodes()`
    3. Resolve AudioParam from target+paramName:
       - 'gain' -> target.getGainNode().gain (BaseSound) or target.getParam('gain') (BaseEffect)
       - 'pan' -> target.getPannerNode().pan (BaseSound only — throw if BaseEffect)
       - 'frequency' -> if target is Oscillator: target.audioSourceNode.frequency; if BaseEffect: target.getParam('frequency')
       - 'detune' -> target.audioSourceNode.detune (Oscillator only)
       - For BaseEffect targets: always use target.getParam(paramName)
    4. Compute absoluteDepth based on depthUnit:
       - Default depthUnit: 'cents' if paramName === 'frequency', else 'ratio'
       - ratio: `Math.abs(paramValue) > 0.001 ? paramValue * depth : depth`
       - cents: `paramValue * (Math.pow(2, depth / 1200) - 1)`
       - absolute: `depth` directly
    5. Create per-connection GainNode, set gain.value = absoluteDepth
    6. Connect oscillator/bufferSource -> connGain -> audioParam
    7. If syncLifecycle, register 'play' listener on target (starts LFO), 'stop'/'end' listener (stops LFO)
    8. If retrigger, register 'play' listener that calls `_restart()` (recreate oscillator node)
    9. Patch target.dispose() if not already patched for this target
    10. Store ConnectionRecord
    11. Return `this`

    `disconnect(target?, paramName?)`:
    - No args: disconnect all connections
    - target only: disconnect all connections to that target
    - target + paramName: disconnect specific connection
    - Calls depthGain.disconnect(audioParam) for each removed connection
    - Removes event listeners if syncLifecycle/retrigger were active
    - Does NOT unpatch dispose (patching is idempotent and cheap)

    `start()`:
    - If no audioContext, throw helpful error
    - If already running, no-op
    - If oscillator is null (stopped previously), call `_initNodes()` and rewire existing connections
    - Start oscillator/bufferSource
    - Set `_isRunning = true`
    - Return `this`

    `stop()`:
    - If not running, no-op
    - Stop oscillator (try/catch for already stopped)
    - Set oscillator to null (will be recreated on next start)
    - Set `_isRunning = false`
    - Return `this`

    `dispose()`:
    - If already disposed, no-op
    - Stop if running
    - Disconnect all connections (calls disconnect())
    - Restore all patched dispose methods
    - Set `_disposed = true`

    `syncToBPM(bpm, noteLength)`:
    - Parse noteLength string ('1/4', '1/8', '1/16', etc.)
    - Calculate Hz: `(bpm / 60) * (numerator / denominator) * 4`
    - Set frequency to calculated value
    - Return `this`

    `frequency` getter/setter:
    - Setter updates `_options.frequency` and if oscillator exists, sets `oscillatorNode.frequency.value` (or regenerates buffer for S&H)

    `depth` getter/setter:
    - Setter updates `_options.depth` and recalculates all per-connection depthGain values

    `type` getter/setter:
    - Setter updates `_type`. If running and switching to/from S&H, must stop current source and create new one of correct type, rewire connections.

    `rampFrequency(value, duration)`:
    - `oscillatorNode.frequency.setTargetAtTime(value, audioContext.currentTime, duration / 3)`
    - For S&H: just set value (buffer regeneration needed for true rate change)

    `rampDepth(value, duration)`:
    - For each connection, `connGain.gain.setTargetAtTime(newAbsoluteDepth, now, duration / 3)`

    **Private helpers:**

    `_initNodes()`:
    - Create OscillatorNode or AudioBufferSourceNode (for S&H)
    - For standard waveforms: create OscillatorNode, set frequency and type
    - For PeriodicWave: create OscillatorNode, call setPeriodicWave()
    - For S&H: create AudioBuffer with stepped random values, create AudioBufferSourceNode with loop=true

    `_rewireConnections()`:
    - For each connection: connect current oscillator/bufferSource -> connection.depthGain
    - Called after oscillator recreation (stop/start cycle, retrigger)

    `_restart()`:
    - If running, stop current oscillator
    - Create new oscillator, rewire, start

    `_cleanupTarget(target)`:
    - Remove all connections for target
    - Remove event listeners from target
    - Remove from disposePatchMap

    `_createSampleAndHoldBuffer(frequency)`:
    - Create 1-second AudioBuffer
    - Fill with stepped random values at the given frequency
    - Return buffer

    `_patchDispose(target)`:
    - If already patched for this target, no-op
    - Store reference to original dispose: `const orig = target.dispose.bind(target)`
    - Replace: `target.dispose = () => { this._cleanupTarget(target); orig() }`
    - Store in `_disposePatchMap`

    `resolveAudioParam(target, paramName)` private helper:
    - Import BaseSound and Oscillator types
    - Import BaseEffect type
    - Switch on paramName for BaseSound targets:
      - 'gain' -> target.getGainNode().gain
      - 'pan' -> target.getPannerNode().pan
      - 'frequency' -> (target as Oscillator).audioSourceNode.frequency (with runtime check)
      - 'detune' -> (target as Oscillator).audioSourceNode.detune (with runtime check)
    - For BaseEffect targets: target.getParam(paramName) — throw if null

  <action>
CR2 fix — The "Create a Synthesizer" example on the landing page has THREE errors:
1. `createEnvelope` is not an exported function — envelopes are passed as options
2. `createOscillator()` returns `Promise<Oscillator>` — missing `await`
3. `synth.play(envelope)` — `play()` takes no arguments

Replace the entire synthesizer code block (lines 45-51) from:
```typescript
import { createEnvelope, createOscillator } from 'ez-web-audio'

const synth = createOscillator({ type: 'sawtooth', note: 'A4' })
const envelope = createEnvelope({ attack: 0.01, decay: 0.2, sustain: 0.3, release: 0.5 })
synth.play(envelope)
```

With:
```typescript
import { createOscillator } from 'ez-web-audio'

const synth = await createOscillator({
  type: 'sawtooth',
  note: 'A4',
  envelope: { attack: 0.01, decay: 0.2, sustain: 0.3, release: 0.5 }
})
synth.play()
```

This matches the actual API: envelope is an option passed to createOscillator, the function is async, and play() takes no arguments.

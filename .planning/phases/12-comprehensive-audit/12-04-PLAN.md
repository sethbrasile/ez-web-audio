Perform a comprehensive dependency health check:

1. **Read package.json** — List all dependencies and devDependencies with current versions.

2. **Confirm zero runtime dependencies** — Verify the `dependencies` field is empty or absent. If any runtime dependencies exist, flag as critical (the library promises zero dependencies).

3. **Run `pnpm outdated`** — Check for outdated packages. Document current vs latest for each.

4. **Run `pnpm audit`** — Check for known vulnerabilities. Document severity and recommendations.

5. **Evaluate each devDependency:**
   - Is it still needed? (e.g., tools that were used during development but no longer needed)
   - Is it the right tool? (e.g., is there a better-maintained alternative?)
   - Is the pinned version reasonable? (exact pin vs range vs latest)

6. **Check lock file health** — Is pnpm-lock.yaml in sync with package.json?

7. **Review build toolchain:**
   - Vite version — any breaking changes in newer versions?
   - TypeScript version — are we on a recent stable release?
   - Vitest version — in sync with Vite?
   - VitePress version — any updates needed?

8. **Check for deprecated packages** — Any dependencies that have been deprecated or archived?

**ensureLoaded() function:**
```typescript
async function ensureLoaded() {
  if (lib) return
  lib = await import('ez-web-audio')
  transport = await lib.createTransport({ bpm: bpm.value, timeSignature: [4, 4], ticksPerBeat: 4 })

  // Load drum samples (from /ez-web-audio/audio/drum-samples/)
  kickTrack = await lib.createBeatTrack(
    ['/ez-web-audio/audio/drum-samples/kick1.wav', '/ez-web-audio/audio/drum-samples/kick2.wav'],
    { numBeats: 32 }
  )
  snareTrack = await lib.createBeatTrack(
    ['/ez-web-audio/audio/drum-samples/snare1.wav', '/ez-web-audio/audio/drum-samples/snare2.wav'],
    { numBeats: 32 }
  )
  hihatTrack = await lib.createBeatTrack(
    ['/ez-web-audio/audio/drum-samples/hihat1.wav', '/ez-web-audio/audio/drum-samples/hihat2.wav'],
    { numBeats: 32 }
  )

  kickTrack.syncTo(transport, { noteType: 1/16 })
  snareTrack.syncTo(transport, { noteType: 1/16 })
  hihatTrack.syncTo(transport, { noteType: 1/16 })

  bassOsc = await lib.createOscillator({ frequency: 55, type: 'sawtooth' })  // E1 bass range
  pianoFont = await lib.createFont('/ez-web-audio/audio/piano.js')

  // createSequence is SYNC — no await
  bassSeq = lib.createSequence(transport, { length: '2m', loop: true })
  pianoSeq = lib.createSequence(transport, { length: '2m', loop: true })

  // Store audioContext reference for playIn offset computation
  audioCtx = (transport as any).audioContext

  // Set up tick handler for playhead
  transport.on('tick', (e: any) => {
    const { bar, beat, tick } = e.detail
    const step = ((bar - 1) * 16) + ((beat - 1) * 4) + tick
    currentStep.value = step % 32
    positionDisplay.value = `${bar}:${beat}`
  })

  // Apply initial preset
  applyPreset(activePreset.value)
}
```

**applyPreset(name):** calls `setPattern()` on kick/snare/hihat, then `bassSeq.clear()` + `pianoSeq.clear()`, then re-registers all events via `seq.at()`. Use `shouldPlay()` guard in each callback. For bass notes, call `bassOsc.playFor(duration)` and set `bassOsc.frequency` before each call. For piano, call `pianoFont.getNote(noteName)?.playIn(Math.max(0, time - audioCtx!.currentTime))`.

**shouldPlay(trackName):** returns false if muted (or if any track is soloed and this one isn't soloed). Handles both drum and melody tracks.

**toggleMute(trackName):** toggles `trackMuted.value[trackName]`. For drum tracks also set `kickTrack.muted = !kickTrack.muted` (etc.). For melody tracks, handled via `shouldPlay()` guard.

**toggleSolo(trackName):** toggles `trackSoloed.value[trackName]`. For drum tracks also set the `.solo` property. For melody tracks, handled via `shouldPlay()` guard.

**BPM watch:** `watch(bpm, (v) => { if (transport) transport.bpm = Math.max(40, Math.min(300, v)) })`

**play/pause/stop functions:** call `transport.start()`, `transport.pause()`, `transport.stop()` and update `playing`/`paused` refs accordingly. `play()` calls `ensureLoaded()` first.

**onUnmounted:** stop transport, stop bassOsc, null all instances, set `lib = null`.

**stepCells computed property:** maps preset note arrays to a 32-element array per track, providing `{ active: boolean, noteName: string | null }` for each step cell. Drum cells have `active` when pattern index is 1. Melody cells show note name when a note triggers at that step index.

**Critical notes:**
1. All audio instances at module level — never in `reactive()` or `ref()`.
2. `createSequence` is synchronous — no await.
3. Event positions must be within sequence length: `'2m'` = 8 beats; last position must be `< 8` beats (e.g., `'2:4:3'` not `'2m'`). Use `'2:3:0'` not `'1m+2n'` for bar 2 beat 3.
4. Bass oscillator bass notes: use `bassOsc.playFor(noteDuration)` pattern for finite notes — prevents continuous tone buildup.
5. Piano playIn offset: `Math.max(0, time - audioCtx.currentTime)`.
6. `transport.tracks` only returns BeatTracks, not Sequences — manage melody mute/solo in component.

Transport event (fires every 16th note with ticksPerBeat=4):
```typescript
transport.on('tick', (e: CustomEvent<{ bar: number; beat: number; tick: number; seconds: number }>) => { ... })
// step index: ((bar - 1) * 16) + ((beat - 1) * 4) + tick  → % 32 for 2-bar loop
```

BeatTrack (public properties):
```typescript
beatTrack.muted: boolean   // silences audio, keeps scheduling
beatTrack.solo: boolean    // when any solo=true, only soloed tracks play
beatTrack.setPattern(pattern: number[]): void  // 0=inactive, 1=active, length must match numBeats
beatTrack.syncTo(transport: Transport, opts: { noteType: number }): void
```

Sequence:
```typescript
seq.at(time: MusicalTimeNotation | string | number, callback: (time: number) => void): void
// time is ABSOLUTE AudioContext time — compute offset: time - audioContext.currentTime
seq.clear(): void  // safe during playback — remove all registered events
// Positions must be strictly LESS THAN sequence length ('2m' = 8 beats, so max is '1:4:3')
```

Oscillator (bass note pattern):

```typescript
// Use playFor(durationSeconds) for finite note duration without clicks
oscillator.frequency = 55  // or change pitch

```

Font (piano soundfont):

**ensureLoaded()** async function (called on first Play):
1. Guard: `if (lib) return`
2. `lib = await import('ez-web-audio')`
3. Destructure: `const { createTransport, createSequence, createBeatTrack, createFont, createOscillator } = lib`
4. `transport = await createTransport({ bpm: bpm.value, timeSignature: [4, 4], ticksPerBeat: 4 })`
5. `audioContext = (transport as any).audioContext as AudioContext`
6. Create 3 BeatTracks: kick, snare, hihat each with `createBeatTrack([url1, url2, url3], { numBeats: 32 })`
7. Apply initial preset pattern to each: `kickTrack.setPattern(PRESETS['Straight Rock'].kick)` etc.
8. Sync each to transport: `kickTrack.syncTo(transport, { noteType: 1/16 })`
9. `bassOsc = await createOscillator({ frequency: 41.2, type: 'sawtooth' })` (E1 ≈ 41.2 Hz, low bass)
10. `pianoFont = await createFont('/ez-web-audio/audio/piano.js')`
11. `bassSeq = createSequence(transport, { length: '2m', loop: true })` (SYNC — no await)
12. `pianoSeq = createSequence(transport, { length: '2m', loop: true })` (SYNC — no await)
13. Call `applyPreset('Straight Rock')` to schedule melody events
14. Register tick handler: compute step, update `currentStep.value` and `positionDisplay.value`

**applyPreset(name)** function:
1. Update drum patterns: `kickTrack?.setPattern(...)`, `snareTrack?.setPattern(...)`, `hihatTrack?.setPattern(...)`
2. `bassSeq?.clear()` and `pianoSeq?.clear()` (safe during playback)
3. Re-register bass events from `PRESETS[name].bassNotes` array: for each `{ time, freq, duration }` → `bassSeq.at(time, (t) => { if (!shouldPlay('bass')) return; const offset = Math.max(0, t - audioContext!.currentTime); bassOsc!.frequency = freq; bassOsc!.playFor(duration) })`
4. Re-register piano events from `PRESETS[name].pianoNotes` array: for each `{ time, note }` → `pianoSeq.at(time, (t) => { if (!shouldPlay('piano')) return; pianoFont!.getNote(note)?.playIn(Math.max(0, t - audioContext!.currentTime)) })`

**shouldPlay(trackName)** — mute/solo guard:
```typescript
function shouldPlay(name: 'bass' | 'piano'): boolean {
  const ts = trackState.value
  const anySoloed = ts.kick.soloed || ts.snare.soloed || ts.hihat.soloed || ts.bass.soloed || ts.piano.soloed
  if (anySoloed) return ts[name].soloed
  return !ts[name].muted
}
```

**toggleMute(track)** — for drum BeatTracks, toggle `.muted` directly and sync to `trackState`. For melody, toggle `trackState.value[track].muted` only (shouldPlay() guards callbacks).

**toggleSolo(track)** — same pattern: BeatTrack `.solo` for drums, trackState-only for melody. BeatTrack solo stacking is handled natively; melody solo is handled by `shouldPlay()`.

**BPM watch**: `watch(bpm, (v) => { if (transport) transport.bpm = Math.max(40, Math.min(300, v)) })`

**Transport controls**:
- `play()`: calls `ensureLoaded()`, then `transport?.start()`, sets `playing = true, paused = false`
- `pause()`: `transport?.pause()`, sets `paused = true`, `currentStep.value = -1`
- `stop()`: `transport?.stop()`, sets `playing = false, paused = false`, `currentStep.value = -1`, `positionDisplay.value = '1:1'`
- `resume()`: `transport?.resume()`, sets `paused = false`

  <name>Task 1: Replace window.setTimeout scheduler loop with WorkerTimer</name>
  <files>src/beat-track.ts</files>
  <action>
Modify BeatTrack to use WorkerTimer for its scheduler loop. This is a surgical replacement — the lookahead scheduling algorithm stays identical, only the timer driver changes.

**Changes to BeatTrack constructor:**
```typescript
import { WorkerTimer } from './utils/worker-timer'

// In constructor:
this.workerTimer = new WorkerTimer() // replace timerID-based scheduling
```

Add a private `workerTimer: WorkerTimer` field. Remove the `timerID: number | null = null` field.

**Changes to scheduler():**
Currently:
```typescript
private scheduler(): void {
  const currentTime = this.audioContext.currentTime
  while (this.nextBeatTime < currentTime + this.scheduleAheadTime) {
    this.scheduleBeat(this.currentBeatIndex, this.nextBeatTime)
    this.advanceToNextBeat()
  }
  this.timerID = window.setTimeout(() => this.scheduler(), this.schedulerInterval)
}
```

Replace with:
```typescript
private scheduler(): void {
  // WorkerTimer calls schedulerTick at regular intervals (replaces recursive setTimeout)
  this.workerTimer.start(() => this.schedulerTick())
}

private schedulerTick(): void {
  const currentTime = this.audioContext.currentTime
  while (this.nextBeatTime < currentTime + this.scheduleAheadTime) {
    this.scheduleBeat(this.currentBeatIndex, this.nextBeatTime)
    this.advanceToNextBeat()
  }
}
```

**Changes to stop():**
Replace `clearTimeout(this.timerID)` with `this.workerTimer.stop()`.
Remove `this.timerID = null` line.

**Changes to pause():**
Replace `clearTimeout(this.timerID); this.timerID = null` with `this.workerTimer.stop()`.

**Changes to resume():**
No change needed — it already calls `this.scheduler()` which now uses WorkerTimer.

**Changes to dispose():**
After `this.stop()`, add `this.workerTimer.dispose()` to clean up the Worker.

Remove the `schedulerInterval = 25` field — it's now handled by WorkerTimer's internal interval.

Keep `scheduleAheadTime = 0.1` — this is the lookahead window, still needed.

**Critical: Do NOT change:**
- scheduleBeat() method — unchanged
- advanceToNextBeat() method — unchanged
- Beat scheduling logic — unchanged
- audioContextAwareTimeout usage for visual timing — unchanged
- Any public API signatures — unchanged

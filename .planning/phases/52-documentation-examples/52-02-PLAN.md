# Plan 52-02: Widen createBeatTrack and createSampler to Accept AudioInput[]

## Goal

`createBeatTrack()` and `createSampler()` currently only accept `string[]` (URLs). Widen their parameter type to `AudioInput[]` so consumers can pass `ArrayBuffer`, `Blob`, or `File` inputs — matching the `createSound()` and `createTrack()` signatures.

## Context

- `AudioInput` is already exported as `string | ArrayBuffer | Blob | File` (line 200 of `src/index.ts`)
- `createSound(input: AudioInput)` already handles all four input types via `load()` (for strings) and `loadFromBuffer()` (for ArrayBuffer/Blob/File)
- `createBeatTrack` and `createSampler` currently call `load(url, 'sound')` which only handles strings
- The private `loadFromBuffer(buffer, type)` function handles `ArrayBuffer` inputs
- The fix is to extract the input-to-Sound resolution logic and use it in both factory functions

1. **Add a private helper function** near the existing `loadFromBuffer` function (around line 206):

```typescript
/**
 * Resolve an AudioInput to a Sound instance.
 * Handles string URLs via load() and ArrayBuffer/Blob/File via loadFromBuffer().
 * @private
 */
async function resolveSound(input: AudioInput): Promise<Sound> {
  if (typeof input === 'string') {
    return load(input, 'sound') as Promise<Sound>
  }
  if (input instanceof ArrayBuffer) {
    return loadFromBuffer(input, 'sound') as Promise<Sound>
  }
  // Blob or File
  const buffer = await input.arrayBuffer()
  return loadFromBuffer(buffer, 'sound') as Promise<Sound>
}
```

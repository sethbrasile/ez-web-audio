  <name>Task 1: Create BaseParamController tests</name>
  <files>src/controllers/base-param-controller.test.ts</files>
  <action>
Create new test file for BaseParamController. This is the base class for parameter control with fluent API.

Add test suites for:

1. **Gain/pan getters and setters:**
   - `gain` getter returns gainNode.gain.value
   - `pan` getter returns pannerNode.pan.value
   - Setting gain updates gainNode
   - Setting pan updates pannerNode

2. **update() fluent API:**
   - `update('gain').to(0.5).from('ratio')` sets gain to 0.5
   - `update('gain').to(50).from('percent')` sets gain to 0.5
   - `update('gain').to(0.3).from('inverseRatio')` sets gain to 0.7
   - `update('pan').to(-1).from('ratio')` sets pan to -1
   - `update('detune').to(100).from('ratio')` sets audioSource.detune.value
   - Throws for unsupported control type
   - Throws for unsupported method type

3. **onPlaySet() scheduling:**
   - `onPlaySet('gain').to(0.5)` adds to startingValues
   - `onPlaySet('gain').to(0.5).at(1.0)` moves to valuesAtTime
   - `onPlaySet('gain').to(0.5).endingAt(1.0)` adds to exponentialValues
   - `onPlaySet('gain').to(0.5).endingAt(1.0, 'linear')` adds to linearValues

4. **onPlayRamp() scheduling:**
   - `onPlayRamp('gain').from(0).to(1).in(0.5)` schedules start value and ramp
   - Verify both starting value and ending ramp added

5. **updateGainNode/updatePannerNode:**
   - `updateGainNode(newNode)` transfers value and updates reference
   - `updatePannerNode(newNode)` transfers value and updates reference

Create mock audioSource with detune property.
Use spies to verify internal array mutations where needed.

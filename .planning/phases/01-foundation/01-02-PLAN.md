Refactor BaseSound to use template method pattern so Track can override core behavior without breaking playIn/playFor/playInAndStopAfter:

**In src/base-sound.ts:**

1. Keep public play() but delegate to protected _play():
   ```typescript
   public async play(): Promise<void> {
     await this._play();
   }

   protected async _play(): Promise<void> {
     await this.playAt(this.audioContext.currentTime);
   }
   ```

2. Similarly for playIn and playFor - they should call _play variants or use playAt directly:
   - playIn(when) calls playAt(currentTime + when) - no change needed, already correct
   - playFor(duration) calls playAt then schedules stop - no change needed

The key fix is that Track currently overrides play() directly, which means super.playIn() calls super.play() which doesn't include Track's position tracking. By having play() call _play(), Track can override _play() and all the play* methods will use the override.

**In src/track.ts:**

1. Change play() override to _play() override:
   ```typescript
   protected override async _play(): Promise<void> {
     await super._play();
     this.audioSourceNode.onended = () => this.stop();
     this.later(this.trackPlayPosition.bind(this));
   }
   ```

2. Remove the existing play() override entirely

3. Now Track.playIn(5) will:
   - Call BaseSound.playIn(5)
   - Which calls playAt(currentTime + 5)
   - playAt schedules the sound AND calls this.later() after sound starts
   - _play is NOT involved in playIn/playAt flow - review this...

Actually, looking at the code more carefully:
- play() calls playAt(currentTime)
- playIn(when) calls playAt(currentTime + when)
- playFor(duration) calls playAt(currentTime) then schedules stop

Track.play() currently:
- Calls super.play() (which calls playAt)
- Then sets onended handler
- Then calls trackPlayPosition

The issue is Track.playIn() calls BaseSound.playIn() which calls playAt() but does NOT run Track's custom logic (onended, trackPlayPosition).

**Fix approach:** Have playAt() call a hook method that Track overrides:

In BaseSound, add at end of playAt():
```typescript
this._onPlaybackStarted();
```

Add empty protected method:
```typescript
protected _onPlaybackStarted(): void {
  // Override in subclasses
}
```

In Track, override:
```typescript
protected override _onPlaybackStarted(): void {
  this.audioSourceNode.onended = () => this.stop();
  this.later(this.trackPlayPosition.bind(this));
}
```

And remove Track's play() override entirely.

This is cleaner than _play() because playAt is the true underlying method.

   ```typescript
   private trackPlayPosition(): void {
     const { audioContext, startedPlayingAt, startOffset } = this;

     const animate = (): void => {
       if (!this._isPlaying) {
         this.rafId = null;
         return;
       }
       this.startOffset = startOffset + audioContext.currentTime - startedPlayingAt;
       this.rafId = requestAnimationFrame(animate);
     };

     this.rafId = requestAnimationFrame(animate);
   }
   ```

3. Update stop() to cancel RAF:
   ```typescript
   public stop(): void {
     // Cancel RAF first
     if (this.rafId !== null) {
       cancelAnimationFrame(this.rafId);
       this.rafId = null;
     }

     this.startOffset = 0;

     if (this._isPlaying) {
       this.audioSourceNode.onended = function () {};
       super.stop();
     }
   }
   ```

4. Update pause() to cancel RAF:
   ```typescript
   public pause(): void {
     // Cancel RAF
     if (this.rafId !== null) {
       cancelAnimationFrame(this.rafId);
       this.rafId = null;
     }

     if (this._isPlaying) {
       const node = this.audioSourceNode;
       node.onended = function () {};
       node.stop();
       this._isPlaying = false;
     }
   }
   ```

**FIX-04: AudioBufferSourceNode disconnect (src/sound.ts):**

1. Update setup() to disconnect old source before creating new:
   ```typescript
   protected setup(): void {
     // Disconnect old source if exists (prevents memory leak)
     if (this.audioSourceNode) {
       try {
         this.audioSourceNode.disconnect();
         this.audioSourceNode.onended = null;

         audioSourceNode.disconnect();
       } catch (e) {
         // Already disconnected
       }
     };

     this.wireConnections();
     this.controller.setValuesAtTimes();
   }
   ```

  <action>
Create `.github/workflows/publish.yml` for automated npm publishing:

```yaml
# Publish to npm when a version tag is pushed
name: Publish to npm

on:
  push:
    tags:
      - 'v*'

jobs:
  publish:
    runs-on: ubuntu-latest
    permissions:
      id-token: write # Required for npm provenance
      contents: read

    steps:
      - uses: actions/checkout@v4

      - name: Install pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 10

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          registry-url: 'https://registry.npmjs.org'
          cache: pnpm

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Run tests
        run: pnpm test run

      - name: Build library
        run: pnpm build:lib

      - name: Publish to npm
        run: npm publish --provenance --access public
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
```

Key aspects:
- Triggers on tags matching v* (v0.1.0, v1.0.0, etc.)
- Uses pnpm 10 to match project's packageManager
- Runs tests before publishing (fail early if tests break)
- Uses `--frozen-lockfile` for reproducible installs
- Includes `--provenance` for supply chain security
- Uses `--access public` since ez-web-audio is a public package
- Requires NPM_TOKEN secret (user will configure this)

   Should contain:

   - package/dist/index.js.map
   - package/dist/index.d.ts
   - package/dist/index.d.ts.map
   - package/README.md
   - package/LICENSE
   - package/package.json

   - src/ folder
   - tests
   - .planning/
   - docs/
   - node_modules/

   ```bash
   mkdir -p /tmp/test-ez-audio
   cd /tmp/test-ez-audio
   npm init -y
   npm install /path/to/ez-web-audio-0.1.0.tgz
   ```

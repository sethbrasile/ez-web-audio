  On line 100, change:
  ```
  analyzer = createAnalyzer(ctx, { fftSize: fftSize.value })
  ```
  to:
  ```
  analyzer = await createAnalyzer(ctx, { fftSize: fftSize.value })
  ```

  The `createAnalyzer` factory function is async (returns `Promise<Analyzer>`), even when an AudioContext is passed directly.

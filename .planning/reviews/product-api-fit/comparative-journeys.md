# Comparative Journeys

Compare EZ, native Web Audio, and alternatives against the same north-star application rather than a feature checklist. Record the canonical path, ownership boundary, recovery path, and evidence for each step.

| Journey stage | User outcome | Required comparison evidence | EZ finding | Native / alternative finding |

| Background media | Run longer media with suitable controls | Streaming, pause, seek, and lifecycle model | Pending audit | Pending audit |
| Global controls | Persist volume and mute across application audio | Routing and application ownership | Pending audit | Pending audit |
| Navigation cleanup | Dispose route or component audio safely | Scope boundary and idempotence | Pending audit | Pending audit |

| Musical extension | Add synthesis or timing when required | Optionality and continuity of mental model | Pending audit | Pending audit |

Note: `Note` extends `MusicallyAware(class {})`. The musical-identity mixin handles identifier parsing and frequency lookup. These tests verify the Note constructor properly passes options through.

**font.test.ts:**

- `play('Z9')` throws descriptive error with available notes listed
- `notes` property holds the array passed to constructor
- Empty font: `new Font([])`, `getNote` returns undefined, `play` throws

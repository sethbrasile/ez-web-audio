    Format:
    ```markdown
    # Changelog

    ## [1.0.0] - Unreleased

    ### Breaking Changes

    #### Method Renames
    - `update('gain').to(0.5).from('ratio')` → `update('gain').to(0.5).as('ratio')` — The `.from()` method on `update().to()` chains is now `.as()` for readability
    - `track.seek(30).from('seconds')` → `track.seek(30).as('seconds')` — The `.from()` method on `seek()` chains is now `.as()`
    - `beat.ifActivePlayIn(offset)` → `beat.playInIfActive(offset)` — Renamed for consistency with `playIfActive()`

    #### Visibility Changes
    - `BaseSound.gainNode` is now `protected` — Use `getGainNode()` for advanced access
    - `BaseSound.pannerNode` is now `protected`
    - `BaseSound.effectChainInput` is now `protected`
    - `BaseSound.startOffset` is now `protected` — Use Track's `position` and `seek()` APIs

    #### Removed APIs
    - `addConnection()`, `removeConnection()`, `getConnection()`, `getNodeFrom()`, and `connections` array removed — Use `addEffect()`/`removeEffect()` instead
    - `OscillatorOpts` type alias removed — Use `OscillatorOptions`
    - `OscillatorOptsFilterValues` type alias removed — Use `OscillatorFilterOptions`
    - `stopAfter` removed from Playable interface (was never implemented; use `playFor()`)

    ### Migration Guide

    [Brief migration examples for each breaking change]
    ```

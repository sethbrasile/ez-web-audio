<objective>
Add build:lib to CI, fix deploy-docs frozen lockfile, harden prepublishOnly, and deduplicate publish workflow build steps.

Purpose: CI currently does not run `pnpm build:lib`, so a PR could break the build without being caught. The deploy-docs workflow uses `pnpm install` without `--frozen-lockfile`, risking non-reproducible installs. The `prepublishOnly` script only builds without running quality gates. The publish workflow runs `build:lib` then `build` (which internally runs `build:lib` again).

Output: Hardened CI/CD pipelines that catch build failures and ensure quality gates run before every publish.
</objective>

**Fix M20 — Expand prepublishOnly:**

In `package.json`, change:
```json
"prepublishOnly": "pnpm build:lib"
```
to:
```json
"prepublishOnly": "pnpm typecheck && pnpm lint && pnpm test --run && pnpm build:lib"
```

This ensures local `npm publish` runs all quality gates. Note: In CI publish workflow, these already run as separate steps, so prepublishOnly is a safety net for manual publishes.

**Fix L25 — Deduplicate publish workflow builds:**

In `.github/workflows/publish.yml`, the workflow currently runs:
1. `pnpm build:lib` (step: "Build library")
2. `pnpm build` (step: "Build full (docs + typedoc)")

But `pnpm build` runs `build:lib && docs:build`, so `build:lib` runs twice. Since the publish workflow needs both lib and docs (for E2E tests), replace the two steps with a single step:

Remove the "Build library" step (line ~41-42) and keep only "Build full" step, OR rename:

```yaml
      - name: Build library and docs
        run: pnpm build
```

Remove the separate "Build library" step entirely. The `pnpm build` script already runs `build:lib` first, so one step handles both.

Additionally, since `prepublishOnly` now runs typecheck/lint/test/build:lib, and the publish workflow already runs these as separate earlier steps, the `npm publish` command at the end will trigger prepublishOnly again — but since the build artifacts already exist and tests already passed, this is a harmless double-check (not a performance concern for a publish job). Leave this as-is for the safety net benefit.

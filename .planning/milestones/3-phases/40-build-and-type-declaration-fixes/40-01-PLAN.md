<task type="auto">
  <name>Task 1: Fix barrel JS files in dist and clean up build scripts</name>
  <files>vite.config.js, package.json, tsconfig.json</files>
  <action>
**Problem 1 (CR1):** `dist/effects/index.d.ts` and `dist/errors/index.d.ts` are generated by `vite-plugin-dts`, but Vite's `preserveModules` + tree-shaking eliminates the corresponding `index.js` barrel files because `dist/index.js` imports directly from concrete files. This breaks `"moduleResolution": "nodenext"` consumers.

**Fix for CR1:** In `vite.config.js`, add the barrel entry points as additional Rollup input entries so Vite always emits them:

```js
build: {
  lib: {
    entry: resolve(__dirname, 'src/index.ts'),
    // ...
  },
  rollupOptions: {
    // Add barrel files as explicit inputs so they are not tree-shaken away
    input: {
      index: resolve(__dirname, 'src/index.ts'),
      'effects/index': resolve(__dirname, 'src/effects/index.ts'),
      'errors/index': resolve(__dirname, 'src/errors/index.ts'),
    },
    // ...
  },
}
```

This forces Rollup to emit `dist/effects/index.js` and `dist/errors/index.js` alongside the `.d.ts` barrels that `vite-plugin-dts` generates.

**Problem 2 (L24):** `build:lib` is `"tsc && vite build"`. The `tsc` emit pass writes `.js` files to `dist/` that Vite immediately overwrites. The `vite-plugin-dts` plugin handles declaration generation, so tsc emit is wasted work.

**Fix for L24:** Change `build:lib` to `"tsc --noEmit && vite build"`. This keeps type checking but skips the wasted emit pass.

**Problem 3 (L23):** `build:ci` and `build:base` are identical to `build`. They serve no purpose.

**Fix for L23:** Remove `build:ci` and `build:base` from `package.json` scripts.

**Problem 4 (L27):** `tsconfig.json` has stale path aliases that don't map to existing directories: `@app/*`, `@common/*`, `@components/*`, `@test/*`.

**Fix for L27:** Remove the four stale path aliases from tsconfig.json `paths`. Keep only: `@/*`, `@controllers/*`, `@utils/*`, `@interfaces/*`.

Apply all four fixes.

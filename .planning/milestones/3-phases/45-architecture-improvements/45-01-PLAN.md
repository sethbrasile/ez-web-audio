  <files>src/track.ts, src/sprite.ts</files>
  <action>
In `src/track.ts`:
- Extract the cleanup logic from the `_onPlaybackStarted()` onended handler into a new private method `_resetPosition()`.
- The onended handler currently does: disconnect node, null onended, check _isPlaying, set _isPlaying=false, emit 'end', call void this.stop().
- Create `private _resetPosition(): void` that encapsulates the position-reset and cleanup logic that `stop()` currently provides (resetting startOffset to 0, stopping position tracking).
- In the onended handler's natural completion path (where _isPlaying is still true), call `_resetPosition()` directly instead of `void this.stop()`. This makes the intent clear: on natural end, we reset position without re-emitting 'stop'.
- Keep the disconnect and _isPlaying=false and 'end' event emission in the onended handler itself, since those are specific to natural completion.
- Add JSDoc: `/** Reset playback position to start. Called on natural completion. @internal */`

In `src/sprite.ts`:
- Add a `dispose()` method to the AudioSprite class.
- The method should: call `this.stopAll()` to stop all active sources, then set `this.activeSources` to a new empty Map (or clear it), then null out the audioBuffer reference.
- Since audioBuffer is a private readonly constructor parameter, you'll need to change it to a private property (remove readonly or use a nullable type `private audioBuffer: AudioBuffer | null`).
- Update `play()` to check if disposed (audioBuffer is null) and throw: `throw new Error('AudioSprite has been disposed')`
- Add JSDoc: `/** Release audio buffer and stop all active sources. After disposal, play() will throw. */`

Create `src/concurrent.test.ts` with three describe blocks per the user's locked decisions:

**describe('play while playing (layering)'):**
Per decision: "Layer/overlap — both instances play simultaneously." Since AudioBufferSourceNode is single-use, each play() creates a new source node.
1. Create a Sound, play() it, verify isPlaying
2. Call play() again without stopping — verify it creates a new audioSourceNode (different object reference from first)
3. Verify both play events fire (attach handler before first play, assert called twice)
4. Verify no errors thrown during overlapping plays
5. Test rapid triple-play: play() x3 in sequence — all three play events should fire

**describe('rapid seek (debounce/coalesce)'):**
Per decision: "Only the last seek in a rapid burst actually takes effect."
Using Track (the only class with seek):
1. Create a Track with a mock buffer of known duration
2. Perform multiple rapid seeks: `track.seek(10).as('seconds')`, `track.seek(20).as('seconds')`, `track.seek(30).as('seconds')`
3. Verify `track.startOffset` equals the last seek value (30)
4. Test with ratio seeks: seek(0.1).as('ratio'), seek(0.5).as('ratio'), seek(0.9).as('ratio') — startOffset should reflect the last value
5. Verify seek events are emitted for each call (the coalescing is at the application level — the library processes each seek, the last one wins positionally)

**describe('double stop (no-op)'):**
Per decision: "Second stop() call is a silent no-op."
1. Create a Sound, play() it, stop() it — verify isPlaying is false
2. Call stop() again — verify no error thrown
3. Attach a stop event handler, play(), stop(), stop() — verify stop handler called exactly once (second stop is no-op because _isPlaying is already false)
4. Test on Track: pause(), stop(), stop() — no error on second stop
5. Test stop() on a sound that was never played — no error (already-stopped state)

**BUG-01 — Oscillator.setup() gain reset (lines 288-289):**

In `src/oscillator.ts` setup() method, the current code is:
```ts
this.gainNode.gain.cancelScheduledValues(0)
this.gainNode.gain.setValueAtTime(this.gainNode.gain.defaultValue, this.audioContext.currentTime)
```

This resets gain to `defaultValue` (1.0) on every play(), discarding any user-set gain via `changeGainTo()` or `update('gain').to()`.

Fix: Capture the current gain value BEFORE canceling scheduled values, then restore it:
```ts
const currentGain = this.gainNode.gain.value
this.gainNode.gain.cancelScheduledValues(0)
this.gainNode.gain.setValueAtTime(currentGain, this.audioContext.currentTime)
```

**BUG-02 — Sound.setup() missing updateAudioSource (line 119):**

In `src/sound.ts` setup() method, after creating and assigning the new AudioBufferSourceNode (line 119: `this.audioSourceNode = audioSourceNode`), the controller is never told about the new source node. Compare with Oscillator.setup() which correctly calls `this.controller.updateAudioSource(oscillator)` at line 292.

Fix: Add `this.controller.updateAudioSource(audioSourceNode)` after line 119 (after `this.audioSourceNode = audioSourceNode`) and before `this.wireConnections()`.

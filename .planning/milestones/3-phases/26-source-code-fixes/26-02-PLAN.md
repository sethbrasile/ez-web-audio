**C-4 — Track.seek() race condition:**
Make the internal `moveToOffset` function async and await `this.stop()`:
```typescript
const moveToOffset = async (offset: number): Promise<void> => {
  const _isPlaying = this._isPlaying
  const adjustedOffset = withinRange(offset, 0, duration)

  // L-3: Only emit 'seek' if position actually changed
  if (adjustedOffset === this.startOffset && !_isPlaying) return

  if (_isPlaying) {
    await this.stop()              // await ensures startOffset=0 completes first
    this.startOffset = adjustedOffset
    this.later(() => this.play())
  } else {
    this.startOffset = adjustedOffset
  }

  this.emit('seek', { time: this.audioContext.currentTime, source: this, position: adjustedOffset })
}
```
The `seek()` method's `.as(type)` chain must return `Promise<void>` since moveToOffset is now async.

**H-4 — Track.resume() at position 0:**
Add a private `_isPaused = false` flag. Set it to `true` in `pause()`, `false` in `stop()` and at the start of `resume()`. Change the resume guard from `this.startOffset > 0` to `this._isPaused`:
```typescript
private _isPaused = false

public pause(): void {
  // ...existing pause logic...

}

public resume(): void {
  if (!this._isPlaying && this._isPaused) {
    this._isPaused = false
    // ...existing resume logic (play from startOffset)...
  }
}

public override async stop(): Promise<void> {
  this._isPaused = false
  // ...existing stop logic...
}
```

**H-2 — Track 'end' event on natural completion:**
In `_onPlaybackStarted()`, update the onended handler to emit 'end' for natural completion:
```typescript
protected override _onPlaybackStarted(): void {
  this.audioSourceNode.onended = () => {
    // Only handle natural completion — stop() sets _isPlaying=false first
    if (this._isPlaying) {
      this._isPlaying = false
      this.emit('end', {
        time: this.audioContext.currentTime,
        source: this,
        duration: this.duration.raw,
      })
      // Cleanup: reset position and tracking
      void this.stop()
    }
  }
  this.later(this.trackPlayPosition.bind(this))
}
```
The key: when `_isPlaying` is true in onended, this is natural completion (user's stop() sets _isPlaying=false before the handler fires). Emit 'end' then call stop() for cleanup. Since _isPlaying is already false when stop() runs, it won't emit 'stop' again (verify this in BaseSound.stop()).

Also include the disconnect cleanup in this handler:
```typescript
try {
  this.audioSourceNode.disconnect()
  this.audioSourceNode.onended = null
} catch { /* Already disconnected */ }
```

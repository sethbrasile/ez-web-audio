**F7 -- Self-cleaning pendingTimerIds (src/beat.ts lines 188-192):**

Currently `trackedTimeout` pushes timer IDs to `pendingTimerIds` but they're only cleared on `cancelPendingTimers()`. During long drum machine sessions, this array grows unbounded with completed timer IDs.

In `trackedTimeout()` (line 188-192), modify to self-remove the timer ID when the callback completes:

```typescript
private trackedTimeout(fn: () => void, delay: number): number {
  const id = this.setTimeout(() => {
    // Remove this timer ID from pending list since it has completed
    const idx = this.pendingTimerIds.indexOf(id)
    if (idx !== -1) this.pendingTimerIds.splice(idx, 1)
    fn()
  }, delay)
  this.pendingTimerIds.push(id)
  return id
}
```

This wraps the original callback in a function that first removes the timer ID from the array, then calls the original callback. The overhead per beat is minimal (one indexOf + splice on a small array).

`cancelPendingTimers()` still works unchanged -- it iterates whatever IDs remain (only active/pending ones now) and clears the array.

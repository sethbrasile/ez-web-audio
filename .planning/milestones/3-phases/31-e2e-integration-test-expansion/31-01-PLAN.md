The `select#filter-type` and `input[type="range"]` controls are ALL `:disabled="!playing"` — they must be enabled by clicking `.play-button` first. After clicking play, the select is enabled and `selectOption` works.
    - `/examples/synthesis` uses `OscillatorDemo.vue`: read it first before assuming selectors; fall back to `input[type="range"]` which is broadly present.

    Structure the file with these test suites:

    **Suite 1: Basic Playback page interactions**
    - Test: "Play Sound button is present and clickable"
      - `page.goto('/examples/basic-playback')`
      - `await page.waitForSelector('.play-btn', { timeout: 10000 })`
      - `await page.waitForLoadState('networkidle')`
      - Verify button is visible: `expect(await page.locator('.play-btn').isVisible()).toBe(true)`

    **Suite 2: Effects page (FilterDemo) interactions**

      - Verify the filter type select is initially disabled:
        `expect(await page.locator('#filter-type').isDisabled()).toBe(true)`
      - Click the play button: `await page.locator('.play-button').click()`
      - Wait for select to become enabled: `await page.waitForFunction(() => !document.querySelector('#filter-type')?.disabled, { timeout: 10000 })`
      - Verify select is now enabled: `expect(await page.locator('#filter-type').isDisabled()).toBe(false)`
      - Select 'highpass' value: `await page.locator('#filter-type').selectOption('highpass')`
      - Verify the select now has value 'highpass': `expect(await page.locator('#filter-type').inputValue()).toBe('highpass')`
      - Click play button again to stop: `await page.locator('.play-button').click()`

    **Suite 3: Drum Machine page — beat toggle interactions**
    - Test: "Beat cell aria-pressed toggles on click"
      - Navigate to `/examples/drum-machine`
      - `await page.waitForSelector('.beat-cell', { timeout: 10000 })`
      - `await page.waitForLoadState('networkidle')`
      - Get the first beat cell: `const beatCell = page.locator('.beat-cell').first()`
      - Read initial `aria-pressed` value: `const initialPressed = await beatCell.getAttribute('aria-pressed')`
      - Click the beat cell: `await beatCell.click()`
      - Read new `aria-pressed` value: `const newPressed = await beatCell.getAttribute('aria-pressed')`
      - Verify it toggled: `expect(newPressed).not.toBe(initialPressed)`
      - This confirms DOM change after interaction, not just error absence

    - Test: "Play button text changes to Stop after click"
      - Navigate to `/examples/drum-machine`
      - `await page.waitForSelector('.play-btn', { timeout: 10000 })`
      - `await page.waitForLoadState('networkidle')`
      - Verify initial text is 'Play': `expect(await page.locator('.play-btn').textContent()).toContain('Play')`
      - Click `.play-btn`
      - `await page.waitForFunction(() => document.querySelector('.play-btn')?.textContent?.trim() === 'Stop', { timeout: 10000 })`
      - Verify button text is now 'Stop': `expect(await page.locator('.play-btn').textContent()).toContain('Stop')`
      - Click again to stop: `await page.locator('.play-btn').click()`
      - `await page.waitForFunction(() => document.querySelector('.play-btn')?.textContent?.trim() === 'Play', { timeout: 10000 })`

    **Suite 4: Synthesis page (OscillatorDemo) interactions**

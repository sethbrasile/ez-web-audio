**getting-started.md** — In the "Your First Sound" section or nearby, add a brief note that `createSound()` and `createTrack()` also accept `ArrayBuffer`, `Blob`, or `File` inputs (not just URL strings). Example:
```typescript
// Load from URL
const sound = await createSound('/sounds/click.mp3')
// Load from ArrayBuffer, Blob, or File (e.g., from file input or fetch)
const buffer = await fetch('/sounds/click.mp3').then(r => r.arrayBuffer())
const sound2 = await createSound(buffer)
```

**concepts.md** — Add these sections:

1. Under or near the Sound/Track sections, add a "Volume Control" subsection documenting the `volume` getter/setter alias:
```typescript
sound.volume = 0.5 // Same as sound.changeGainTo(0.5)
console.log(sound.volume) // 0.5
```
Note that `volume` delegates to `changeGainTo()` — same validation applies (negative throws, >1 warns).

2. Add an "Events" section documenting:
  - BaseSound emits typed events: 'play', 'stop', 'end', 'pause', 'resume', 'seek', 'warning'
  - Event detail `source` field is typed as `AudioEventSource` (union of `BaseSound | BeatTrack | LayeredSound`)
  - Event map types are exported: `SoundEventMap`, `SoundEventType`, `BeatTrackEventMap`, `LayeredSoundEventMap`, `AudioEventSource`, plus detail types (`PlayEventDetail`, `StopEventDetail`, `EndEventDetail`, etc.)
  - `TypedEventEmitter<TMap>` exported for advanced consumers building custom event-driven audio classes
  - Example: `sound.on('play', (e) => { console.log(e.detail.source) })` — source is typed

**utilities.md** — Add these:

1. In the "Batch Loading" section, add `createTracks()` alongside `createSounds()`:
```typescript
import { createTracks } from 'ez-web-audio'

const tracks = await createTracks(
  ['/audio/song1.mp3', '/audio/song2.mp3'],
  (loaded, total, url) => {
    console.log(`Loaded ${loaded}/${total}: ${url}`)
  }
)
```

2. Add a "Noise Generation" section:
```typescript
import { createNoise } from 'ez-web-audio'

const white = await createNoise('white') // Equal energy across all frequencies
const pink = await createNoise('pink')   // 1/f spectrum — natural-sounding
const brown = await createNoise('brown') // Random walk — deep rumble
```
Explain: white noise is flat spectrum (hiss), pink noise rolls off 3dB/octave (natural ambience), brown noise rolls off 6dB/octave (deep rumble). All return a looped `Sound` instance.

**parameter-control.md** — Add documentation for narrowed ControlType:

1. Add a subsection explaining that `Sound.update()`, `Sound.onPlaySet()`, and `Sound.onPlayRamp()` accept `SoundControlType` which is `'gain' | 'pan' | 'detune'`. `Oscillator` overrides to accept full `ControlType` (which also includes `'frequency'`). This means TypeScript will catch `sound.update('frequency')` as a compile error — only oscillators support frequency control.

```typescript
import type { SoundControlType, OscillatorControlType } from 'ez-web-audio'

// Sound only accepts 'gain' | 'pan' | 'detune'
sound.update('gain').to(0.5).as('ratio') // OK
sound.update('frequency') // TypeScript error!

// Oscillator accepts all control types including 'frequency'
osc.update('frequency').to(880).as('ratio') // OK
```

<task type="auto">
  <name>Task 2: Add createNoise factory and volume alias</name>
  <files>src/utils/noise.ts, src/index.ts, src/base-sound.ts, src/base-sound.test.ts</files>
  <action>
1. **Create `src/utils/noise.ts`** with noise buffer generation:
   - `createPinkNoiseBuffer(audioContext: AudioContext): AudioBuffer` — uses Voss-McCartney algorithm (sum of octave-band random values). Generate 1 second of pink noise at the audioContext's sample rate into a mono AudioBuffer.
   - `createBrownNoiseBuffer(audioContext: AudioContext): AudioBuffer` — cumulative random walk algorithm. Each sample = previous + random(-0.02..0.02), clamped to [-1, 1]. Generate 1 second of mono brown noise.
   - Export both functions.

2. **Add `createNoise()` factory in `src/index.ts`:**
   - Signature: `createNoise(type: 'white' | 'pink' | 'brown'): Promise<Sound>`
   - Implementation:
     - `'white'`: delegates to existing `createWhiteNoise()` logic (inline, or call it directly)
     - `'pink'`: calls `createPinkNoiseBuffer()` from noise.ts, wraps in `new Sound(audioContext, buffer)`
     - `'brown'`: calls `createBrownNoiseBuffer()` from noise.ts, wraps in `new Sound(audioContext, buffer)`
   - Add JSDoc with `@example` showing `createNoise('pink')`.
   - Export `createNoise` in the named exports.

3. **Add `volume` alias on `BaseSound`:**
   - In `src/base-sound.ts`, add:
     ```typescript
     public get volume(): number {
       return this.gainNode.gain.value
     }
     public set volume(value: number) {
       this.changeGainTo(value)
     }
     ```
   - Add JSDoc: "Alias for gain. Get/set the volume (0 = silent, 1 = full volume). Values > 1 amplify and may distort."

4. **Add tests:**
   - In `src/base-sound.test.ts` (or the appropriate split test file): test `volume` getter returns gain value, setter calls changeGainTo behavior (negative throws, >1 warns).
   - In `src/index.test.ts`: test `createNoise('pink')`, `createNoise('brown')`, `createNoise('white')` each return a Sound with a non-empty audioBuffer.
  </action>

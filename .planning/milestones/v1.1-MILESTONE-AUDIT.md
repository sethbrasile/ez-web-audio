## Tech Debt

### Phase 15: Test Coverage

1. **vite.config.js missing e2e/ exclusion** (Warning)
   - Vitest picks up Playwright test files and fails them
   - Fix: Add `exclude: ['e2e/**']` to Vitest test config
   - Impact: Pollutes unit test output, doesn't block E2E tests

2. **Hard-coded 3s wait for Vue hydration** (Info)
   - E2E tests use `waitForTimeout(3000)` instead of element-based waits
   - Reason: VitePress SPA hydration timing makes element checks unreliable
   - Impact: Functional but fragile under slow CI

3. **Minimal E2E UI verification** (Info)
   - Tests only verify no JavaScript errors, not actual UI rendering
   - Deliberate design choice per Phase 15 plan
   - Impact: Won't catch visual regressions, only runtime errors

### Phase 16: SEO & Discoverability

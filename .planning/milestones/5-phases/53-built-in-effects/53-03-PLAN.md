# Plan 53-03: Reverb Effect (Convolution + Algorithmic)

## Objective

Build the reverb effect with two modes auto-detected from the argument: `createReverb('hall.wav')` loads an impulse response for convolution reverb, `createReverb({ decay: 2 })` generates algorithmic reverb using a Schroeder network. Single smart factory, two implementations behind one interface.

## Context

@src/effects/base-effect.ts (BaseEffect to extend)
@src/effects/delay-effect.ts (reference: DelayNode usage pattern)
@src/effects/filter-effect.ts (reference: BiquadFilterNode usage)
@src/effects/index.ts (exports to update)
@src/audio-context.ts (getOrCreateAudioContext)
@CLAUDE.md (project conventions)

## must_haves

- createReverb('url') returns Promise<ReverbEffect> with convolution reverb
- createReverb({ decay: 2, preDelay: 0.02 }) returns ReverbEffect with algorithmic reverb
- createReverb() with no args returns algorithmic reverb with good defaults
- Both modes implement Effect interface and work with addEffect()
- Algorithmic reverb uses Schroeder network (4 comb + 2 allpass filters)

  </behavior>
  <action>
    Create `src/effects/reverb-effect.ts`:

    1. Types:
       - `AlgorithmicReverbOptions`: `decay?: number` (default 1.5, seconds), `preDelay?: number` (default 0.01), `damping?: number` (default 0.3, 0-1), `mix?: number` (default 1)
       - `ConvolutionReverbOptions`: `mix?: number`, `normalize?: boolean` (default true)

    2. `ReverbEffect` class extending `BaseEffect`:
       - Private `_mode: 'convolution' | 'algorithmic'`
       - Two construction paths (private, used by factory):

       **Algorithmic mode (Schroeder reverb):**
       - Pre-delay: single DelayNode
       - 4 parallel comb filters, each = DelayNode + GainNode (feedback) + BiquadFilterNode (lowpass for damping)
       - Comb delay times (standard Schroeder): [0.0297, 0.0371, 0.0411, 0.0437] scaled by (decay / 1.5)
       - Comb feedback gains: 0.84 (adjusted by decay)
       - 2 series allpass filters, each = DelayNode + GainNode
       - Allpass delay times: [0.005, 0.0017]
       - Allpass gain: 0.7
       - Routing: inputNode -> preDelay -> [4 comb filters in parallel] -> combMerge (GainNode, gain=0.25) -> [allpass1 -> allpass2] -> wetGain
       - Each comb filter: combInput -> combDelay -> combFilter -> combFeedback -> combDelay (loop), combFilter -> combMerge
       - Damping: lowpass frequency = 200 + (1 - damping) * 18000 Hz (0 = dark, 1 = very dark)

       **Convolution mode:**
       - Single ConvolverNode
       - Routing: inputNode -> convolverNode -> wetGain
       - `normalize` option controls ConvolverNode.normalize

       Getters/setters for decay, preDelay, damping (algorithmic only — throw or no-op in convolution mode).
       Read-only `mode` getter.

    3. `getAudioParam()`: map 'preDelay' -> preDelayNode.delayTime (algorithmic), others null (decay/damping control multiple nodes so setter handles it manually)

    4. `decay` setter: recalculate all comb feedback gains and delay times
    5. `damping` setter: update all comb lowpass filter frequencies

    Write tests for algorithmic mode. Test that nodes are created and connected, that getters/setters work, and that mode returns 'algorithmic'.
  </action>

  </verify>

# Plan 53-04: EQ Effect

## Objective

Build a three-band EQ effect using three cascaded BiquadFilterNodes (lowshelf + peaking + highshelf). Simple API: `createEQ({ low: 3, mid: -2, high: 4 })` with gain values in dB.

## Context

@src/effects/base-effect.ts (BaseEffect to extend)
@src/effects/filter-effect.ts (reference: BiquadFilterNode usage)
@src/effects/index.ts (exports to update)
@src/audio-context.ts (getOrCreateAudioContext)
@CLAUDE.md (project conventions)

## must_haves

- createEQ() with no args creates flat EQ (all gains at 0 dB)
- createEQ({ low: 3, mid: -2, high: 4 }) applies gain in dB
- Getters/setters for low, mid, high
- rampTo() works for all three bands
- Works with addEffect() on any sound type

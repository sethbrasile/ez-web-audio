    ## PolySynth Construction
    - new PolySynth(ctx, { maxVoices: 4 }) creates instance with max 4 voices
    - new PolySynth(ctx) defaults to maxVoices: 8
    - maxVoices getter returns the configured max
    - activeVoices returns 0 initially
    - availableVoices returns maxVoices initially

    ## Basic Playback (SYNTH-01)
    - play({ frequency: 440 }) returns a VoiceHandle with active === true
    - play({ frequency: 440 }) creates an Oscillator internally and calls its play()
    - play({ frequency: 440, gain: 0.7 }) sets per-voice gain to 0.7
    - After play(), activeVoices increments by 1
    - After play(), availableVoices decrements by 1
    - Multiple play() calls with different frequencies all produce active handles
    - Three simultaneous play() calls: activeVoices === 3

    ## VoiceHandle API
    - handle.active === true while voice is playing
    - handle.update('gain').to(0.5).as('ratio') forwards to underlying oscillator
    - handle.update('frequency').to(880).as('ratio') forwards to underlying oscillator
    - handle.stop() stops the voice and marks handle as inactive
    - After handle.stop(): handle.active === false
    - After handle.stop(): activeVoices decrements
    - Stale handle (after stop): update() returns safely (no-op), no throw
    - Stale handle: stop() returns safely (no-op), no throw

    ## Same-Frequency Retrigger
    - play({ frequency: 440 }) twice reuses the same voice (activeVoices stays 1)
    - Retrigger returns a NEW handle (old handle becomes stale)
    - Old handle.active === false after retrigger

    ## Voice Stealing (SYNTH-02) — LRU Strategy (default)
    - With maxVoices: 2, play three notes: third steals oldest-released voice first
    - If no released voices, steals oldest-active voice
    - Stolen voice's handle becomes stale (handle.active === false)
    - 'voicestolen' event fires with stolen frequency and new frequency

    ## Voice Stealing — oldest-active Strategy
    - new PolySynth(ctx, { maxVoices: 2, stealStrategy: 'oldest-active' })
    - Always steals the voice with earliest startedAt, regardless of release state

    ## Voice Stealing — quietest Strategy
    - new PolySynth(ctx, { maxVoices: 2, stealStrategy: 'quietest' })
    - Steals the voice with lowest current gain

    ## stopAll()
    - stopAll() stops all active voices
    - After stopAll(): activeVoices === 0
    - All outstanding handles become stale

    ## Shared Output Bus
    - All voices route through a shared GainNode -> StereoPannerNode -> destination
    - polySynth.update('gain').to(0.5).as('ratio') sets master gain
    - polySynth.changePanTo(-0.5) sets master pan
    - polySynth.addEffect(effect) wires effect into shared bus
    - polySynth.removeEffect(effect) removes effect from shared bus
    - polySynth.setAnalyzer(analyzer) taps shared bus output

    ## Dispose
    - dispose() stops all voices and disconnects shared bus
    - After dispose: play() throws
    - dispose() is idempotent

    ## Voice Factory
    - Default factory creates Oscillator with PolySynth's type/envelope/filter config
    - Custom createVoice factory: new PolySynth(ctx, { createVoice: (ctx) => new Oscillator(ctx, { type: 'square' }) })
    - Custom factory's oscillator is used for voices

    ## Events
    - 'voicestolen' event detail has: stolenFrequency, newFrequency, time, source

       **VoiceHandle class:**
       ```typescript
       export class VoiceHandle {
         private _active = true
         constructor(
           private oscillator: Oscillator,
           private onStop: () => void,
         ) {}

         get active(): boolean { return this._active }

         update(type: ControlType): { to: (value: number) => { as: (method: RatioType) => void } } {
           if (!this._active) return NO_OP_UPDATE
           return this.oscillator.update(type)
         }

         // Similar no-op wrappers for onPlaySet, onPlayRamp

         async stop(): Promise<void> {
           if (!this._active) return
           this._active = false
           this.onStop()
           await this.oscillator.stop()
         }

         _invalidate(): void { this._active = false }
       }
       ```
       Create `NO_OP_UPDATE`, `NO_OP_ON_PLAY_SET`, `NO_OP_ON_PLAY_RAMP` constants that return safe no-op builder chains.

       **VoiceEntry tracking:**
       ```typescript
       interface VoiceEntry {
         oscillator: Oscillator
         handle: VoiceHandle | null
         state: 'active' | 'released' | 'available'
         startedAt: number
         releasedAt: number
         frequency: number
       }
       ```

       **PolySynth class** extends `TypedEventEmitter<PolySynthEventMap>`:
       - Constructor: creates shared bus nodes (masterGainInput GainNode, masterGain GainNode, masterPan StereoPannerNode), wires them to destination. Stores options. Sets up effect chain following BaseSound's wireEffectChain pattern but self-contained.
       - `play(options: PlayOptions): VoiceHandle` — synchronous, returns handle immediately:
         1. Check same-frequency retrigger: scan voices for matching frequency in 'active' state. If found, retrigger (invalidate old handle, call oscillator.play() which re-triggers envelope, return new handle).
         2. Check for available voice (state === 'available'): allocate it.
         3. If no available voice and pool not full: create new Oscillator via factory, add to pool.
         4. If pool full: steal voice per strategy.
         5. Configure voice: set frequency, gain, setDestination to shared bus input, call play().
         6. Return new VoiceHandle.
       - Steal strategies:
         - 'lru': find oldest releasedAt among 'released' voices; if none, oldest startedAt among 'active'
         - 'oldest-active': always oldest startedAt
         - 'quietest': lowest gain value (use oscillator's gainNode.gain.value)
       - `stopAll()`: stop all active voices, invalidate all handles, set all to 'available'
       - `update('gain')`, `changePanTo()`, etc. on shared bus master nodes
       - `addEffect()`, `removeEffect()`, `setAnalyzer()` on shared bus
       - `dispose()`: stopAll, disconnect shared bus nodes, dispose all oscillators, silence events
       - `get activeVoices()`: count voices with state 'active'
       - `get availableVoices()`: maxVoices - activeVoices
       - Voice release handling: each voice's oscillator 'stop'/'end' event updates VoiceEntry state to 'released', then 'available' after any release phase

<!-- From CONTEXT.md — locked decisions on notation support -->

Musical time notation types:
- Note values: "1n" (whole=4 beats), "2n" (half=2), "4n" (quarter=1), "8n" (eighth=0.5), "16n" (sixteenth=0.25)
- Triplets: "4t" (2/3 beat), "8t" (1/3 beat), "16t" (1/6 beat)
- Dotted: "4n." (1.5 beats), "8n." (0.75 beats)
- Measures: "1m" (beatsPerBar beats), "2m" (2*beatsPerBar), "4m"
- Bar:beat:tick: "2:1:0" → (bar-1)*beatsPerBar + (beat-1) + tick/ticksPerBeat → beats → seconds

From src/transport.ts:
```typescript
interface TransportPosition {
  bar: number    // 1-indexed
  beat: number   // 1-indexed
  tick: number   // 0-indexed
  seconds: number
}
```

Time signature: [beatsPerBar, beatUnit] — default [4, 4]
Ticks per beat: default 4 (16th note resolution)

    ## musicalTimeToBeats(notation, beatsPerBar?, ticksPerBeat?)
    Returns beat count (BPM-independent). beatsPerBar defaults to 4, ticksPerBeat defaults to 4.

    Note values:
    - musicalTimeToBeats('1n') → 4.0 (whole note)
    - musicalTimeToBeats('2n') → 2.0 (half note)
    - musicalTimeToBeats('4n') → 1.0 (quarter note)
    - musicalTimeToBeats('8n') → 0.5 (eighth note)
    - musicalTimeToBeats('16n') → 0.25 (sixteenth note)
    - musicalTimeToBeats('32n') → 0.125 (thirty-second note)

    Triplets (multiply by 2/3):
    - musicalTimeToBeats('4t') → 2/3 (~0.6667)
    - musicalTimeToBeats('8t') → 1/3 (~0.3333)
    - musicalTimeToBeats('16t') → 1/6 (~0.1667)

    Dotted (multiply by 1.5):
    - musicalTimeToBeats('4n.') → 1.5
    - musicalTimeToBeats('8n.') → 0.75
    - musicalTimeToBeats('2n.') → 3.0

    Measures:
    - musicalTimeToBeats('1m') → 4 (in 4/4)
    - musicalTimeToBeats('2m') → 8
    - musicalTimeToBeats('4m') → 16
    - musicalTimeToBeats('1m', 3) → 3 (in 3/4)
    - musicalTimeToBeats('2m', 3) → 6

    Bar:beat:tick positioning:
    - musicalTimeToBeats('1:1:0') → 0 (start)
    - musicalTimeToBeats('1:2:0') → 1 (second beat)
    - musicalTimeToBeats('2:1:0') → 4 (second bar in 4/4)
    - musicalTimeToBeats('2:1:0', 3) → 3 (second bar in 3/4)
    - musicalTimeToBeats('1:1:2') → 0.5 (two ticks in, ticksPerBeat=4)
    - musicalTimeToBeats('1:1:2', 4, 8) → 0.25 (two ticks in, ticksPerBeat=8)

    Numeric passthrough:
    - musicalTimeToBeats(2.5) → 2.5 (already in beats)

    Invalid input:
    - musicalTimeToBeats('xyz') → throws Error with descriptive message
    - musicalTimeToBeats('0n') → throws Error
    - musicalTimeToBeats('') → throws Error

    ## parseMusicalTime(notation, bpm, timeSignature?, ticksPerBeat?)
    Returns seconds. timeSignature defaults to [4, 4], ticksPerBeat defaults to 4.

    - parseMusicalTime('4n', 120) → 0.5
    - parseMusicalTime('8n', 120) → 0.25
    - parseMusicalTime('1m', 120) → 2.0
    - parseMusicalTime('4n', 60) → 1.0
    - parseMusicalTime('8t', 120) → 1/6 (~0.1667)
    - parseMusicalTime('4n.', 120) → 0.75
    - parseMusicalTime('2:1:0', 120, [4, 4]) → 2.0 (bar 2 starts at 2s in 4/4 at 120)
    - parseMusicalTime(2, 120) → 1.0 (2 beats at 120 BPM)
    - parseMusicalTime('4n', 0) → throws (BPM must be > 0)

    ## isMusicalTimeNotation(value)
    Type guard — returns true for valid notation strings, false otherwise.
    - isMusicalTimeNotation('4n') → true
    - isMusicalTimeNotation('8t') → true
    - isMusicalTimeNotation('1m') → true
    - isMusicalTimeNotation('2:1:0') → true
    - isMusicalTimeNotation('xyz') → false
    - isMusicalTimeNotation(42) → false
  </behavior>

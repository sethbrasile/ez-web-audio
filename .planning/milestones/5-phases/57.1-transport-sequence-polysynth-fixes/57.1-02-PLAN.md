1. **Same-beat fix (QC-1-08):** In `_scheduleEventsInWindow()`, change the scheduling logic so that `lastScheduledBeat` is updated to the highest beat scheduled across ALL events in the window, not after each individual event. Replace the scheduling loop:

```typescript
// Schedule events in window
let highestScheduledBeat = this.lastScheduledBeat

for (const event of this.events) {
  const eventBeat = event.beats

  // Handle events in the current window — use >= for same-beat events
  if (eventBeat > this.lastScheduledBeat && eventBeat < windowEndBeat) {
    // Calculate the exact AudioContext time for this event
    const beatOffset = eventBeat - currentSeqBeat
    const timeOffset = beatOffset / beatsPerSecond
    const eventTime = currentTime + timeOffset

    // Build position (QC-1-10 fix: use loopIteration directly)
    const totalBeats = this.loopIteration * this.lengthInBeats + eventBeat
    const bar = Math.floor(totalBeats / beatsPerBar) + 1
    const beatInBar = Math.floor(totalBeats % beatsPerBar) + 1
    const tickInBeat = Math.round((totalBeats % 1) * ticksPerBeat)

    const position: TransportPosition = {
      bar,
      beat: beatInBar,
      tick: tickInBeat,
      seconds: eventTime - this.transportStartTime,
    }

    event.callback(eventTime, position)

    this.emit('event', {
      time: eventTime,
      position,
      eventId: event.id,
      source: this,
    })

    if (eventBeat > highestScheduledBeat) {
      highestScheduledBeat = eventBeat
    }
  }

  // Handle events that wrap around in a looping sequence
  if (this._loop && windowEndBeat >= this.lengthInBeats) {
    const wrappedBeat = eventBeat
    const wrappedWindowEnd = windowEndBeat - this.lengthInBeats
    if (wrappedBeat < wrappedWindowEnd && wrappedBeat <= this.lastScheduledBeat) {
      // This event wraps to the next loop iteration
      // It will be caught in the next scheduler tick after lastScheduledBeat is reset
    }
  }
}

this.lastScheduledBeat = highestScheduledBeat
```

The key changes:
- `lastScheduledBeat` is only updated AFTER the entire loop (not inside per-event)
- Track `highestScheduledBeat` as a local variable across all events
- Position calculation uses `this.loopIteration * this.lengthInBeats` (fix QC-1-10)

2. **Loop position fix (QC-1-10):** Already addressed in step 1 — changed `(this.loopIteration > 0 ? (this.loopIteration - 1) : 0)` to `this.loopIteration`.

1. In `parseMusicalTime()`, add beatUnit scaling. The current formula is:
```typescript
const beats = musicalTimeToBeats(notation, timeSignature[0], ticksPerBeat)
return beats * (60 / bpm)
```

Change to:
```typescript
const beats = musicalTimeToBeats(notation, timeSignature[0], ticksPerBeat)
const beatUnit = timeSignature[1]
// Scale by beatUnit: in 4/4, quarter=1 beat (scale=1.0).
// In 6/8, eighth=1 beat (scale=0.5). A "4n" in 6/8 = 2 eighth-note beats.
const beatUnitScale = 4 / beatUnit
return beats * (60 / bpm) * beatUnitScale
```

This means:
- In 4/4 (beatUnit=4): `scale = 4/4 = 1.0` — no change
- In 6/8 (beatUnit=8): `scale = 4/8 = 0.5` — a quarter note in seconds is half what it would be in 4/4
- In 2/2 (beatUnit=2): `scale = 4/2 = 2.0` — a quarter note is twice as long (BPM refers to half notes)

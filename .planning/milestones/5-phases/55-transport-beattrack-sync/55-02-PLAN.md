Create `src/transport.ts` with the full Transport class. Key implementation details:

**Scheduler pattern** — same as BeatTrack's lookahead scheduler but driven by WorkerTimer:
```typescript
private scheduleAheadTime = 0.1  // 100ms lookahead (match BeatTrack)
private nextTickTime = 0
private currentTickIndex = 0     // absolute tick counter

private schedulerTick(): void {
  const currentTime = this.audioContext.currentTime
  while (this.nextTickTime < currentTime + this.scheduleAheadTime) {
    this.emitTickAt(this.nextTickTime)
    this.advancePosition()
  }
}
```

**Position calculation:**
```typescript
private advancePosition(): void {
  const tickDuration = 60 / (this.bpm * this.ticksPerBeat) // seconds per tick
  this.nextTickTime += tickDuration
  this.currentTickIndex++

  // Derive bar/beat/tick from absolute tick count
  const ticksPerBar = this.timeSignature[0] * this.ticksPerBeat
  const bar = Math.floor(this.currentTickIndex / ticksPerBar) + 1
  const beatInBar = Math.floor((this.currentTickIndex % ticksPerBar) / this.ticksPerBeat) + 1
  const tickInBeat = this.currentTickIndex % this.ticksPerBeat

  this._position = { bar, beat: beatInBar, tick: tickInBeat, seconds: this.nextTickTime - this.startTime }
}
```

**Pause/resume:**
- pause() saves `this.pausedPosition` and `this.pausedTickIndex`
- resume() restores position, sets `this.nextTickTime = audioContext.currentTime` (prevent catch-up burst, same pattern as BeatTrack)

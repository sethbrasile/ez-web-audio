### Key changes

1. **convertValue utility** (QC-1-07): Extracted ratio conversion logic into `src/utils/convert-value.ts`. Used by BaseParamController, GrainPlayer, and PolySynth — prevents future reimplementation bugs.

2. **GrainPlayer/PolySynth fix** (QC-1-07): Both classes' `update().as()` methods previously ignored the RatioType parameter. Now correctly convert percent (50 -> 0.5) and inverseRatio (0.3 -> 0.7).

3. **AudioSprite validation** (QC-1-16): Constructor now validates `end >= start` for all sprite definitions. Previously, `end < start` produced negative durations silently.

4. **LayeredSound gain routing** (QC-1-18): `setGain()` now modifies the shared output bus GainNode instead of overriding individual layer gains.

5. **Crossfade fixes** (QC-1-19, QC-1-20): Replaced `async` setTimeout callback with sync + `.catch()` to prevent unhandled rejections. Uses `changeGainTo()` instead of raw AudioParam to sync `_targetGain`.

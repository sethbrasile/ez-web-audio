<task id="1" title="Create convertValue utility">
**What**: Create `src/utils/convert-value.ts` exporting `convertValue(value: number, method: RatioType): number`.

**Implementation**:
```typescript
import type { RatioType } from '@controllers/base-param-controller'

export function convertValue(value: number, method: RatioType): number {
  switch (method) {
    case 'ratio':
      return value
    case 'inverseRatio':
      return 1 - value
    case 'percent':
      return value / 100
    default:
      throw new Error(`Unsupported ratio type: '${method}'. Supported types: 'ratio', 'inverseRatio', 'percent'.`)
  }
}
```

**Tests**: Create `src/utils/convert-value.test.ts` with tests for all three ratio types and the error case.

<task id="6" title="Fix crossfade afterFade:'stop' unhandled rejection">
**What**: The crossfade function uses `async` inside `setTimeout`, which means if `fromTrack.stop()` throws, it becomes an unhandled rejection.

**File**: `src/utils/crossfade.ts`
**Change**: Replace the `setTimeout` callback (line 124-143). Wrap the async operations in try/catch and use `.catch()` for the stop:

```typescript
return new Promise((resolve) => {
  globalThis.setTimeout(() => {
    fromGain.cancelScheduledValues(0)

    if (afterFade === 'continue') {
      fromGain.setValueAtTime(0, audioContext.currentTime)
    }
    else if (afterFade === 'stop') {
      fromTrack.stop().catch(() => {
        // Stop may reject if track is already stopped or disposed — safe to ignore
      })
      fromTrack.changeGainTo(1.0)
    }
    else {
      // 'pause' (default)
      fromTrack.pause()
      fromTrack.changeGainTo(1.0)
    }

    resolve()
  }, duration * 1000)
})
```

Key changes:
1. Replace `async` setTimeout callback with sync + `.catch()` on the stop promise
2. Use `fromTrack.changeGainTo(1.0)` instead of raw `fromGain.setValueAtTime(1.0, ...)` — this syncs `_targetGain`
3. Same for the 'pause' path — use `changeGainTo(1.0)` to restore `_targetGain`

**Tests**: Add tests in `crossfade.test.ts`:
- afterFade:'stop' calls track.stop() and restores gain
- afterFade:'continue' sets gain to 0 but does not stop/pause
- afterFade:'stop' does not produce unhandled rejection if stop() rejects
</task>

  <behavior>
    ## GrainPlayer Construction
    - Creates GrainPlayer with default options (grainSize=0.1, overlap=0.05, position=0, pitch=0, jitter=0, loop=true)
    - Creates GrainPlayer with custom options (all overridable)
    - Throws on disposed instance when calling play()
    - Constructor creates shared bus: sharedBusInput -> masterGain -> masterPan -> destination

    ## Grain Scheduling (play/stop lifecycle)
    - play() starts scheduling loop, emits 'play' event
    - play() on already-playing instance is a no-op (does not restart)
    - stop() stops scheduling, emits 'stop' event
    - stop() on already-stopped instance is a no-op
    - stop() clears the scheduling timer

    ## Pause/Resume
    - pause() stops scheduling new grains, emits 'pause' event
    - resume() restarts scheduling from same position, emits 'resume' event
    - pause() on non-playing instance is a no-op
    - resume() on non-paused instance is a no-op

    ## Position Control (SYNTH-03)
    - position defaults to 0
    - position can be set between 0 and 1
    - position clamps to [0, 1] range
    - position change takes effect on next grain

    ## Pitch Shifting (SYNTH-04)
    - pitch defaults to 0 (semitones)
    - pitch=12 results in playbackRate=2.0
    - pitch=-12 results in playbackRate=0.5
    - pitch=7 results in playbackRate≈1.4983 (fifth up)
    - playbackRate property provides direct ratio control
    - Setting pitch updates playbackRate and vice versa

    ## Grain Parameters
    - grainSize can be set at runtime (takes effect on next grain)
    - overlap can be set at runtime
    - jitter can be set at runtime (0-1 range)
    - grainSize minimum clamped to 0.01
    - hop size (grainSize - overlap) minimum clamped to 0.001

    ## Master Controls
    - update('gain').to(0.5).as('ratio') sets master gain
    - update('pan').to(-1).as('ratio') sets master pan
    - changeGainTo(value) sets gain directly
    - changePanTo(value) sets pan directly

    ## Effects Chain
    - addEffect() inserts effect into shared bus chain
    - removeEffect() removes effect from chain
    - getEffects() returns readonly copy
    - setAnalyzer() attaches/detaches analyzer
    - setDestination() changes output target

    ## Dispose
    - dispose() stops playback, disconnects nodes, sets disposed=true
    - dispose() is idempotent
    - disposed property returns true after dispose
    - play() throws after dispose

    ## Event Types
    - GrainPlayerEventMap has play, stop, pause, resume events
    - AudioEventSource union includes GrainPlayer

Create `src/grain-player.ts` with:

1. **GrainPlayerOptions interface:**
   - `grainSize?: number` (default 0.1 seconds)
   - `overlap?: number` (default 0.05 seconds)
   - `position?: number` (default 0, range 0-1)
   - `pitch?: number` (default 0, semitones)
   - `jitter?: number` (default 0, range 0-1)
   - `loop?: boolean` (default true)
   - `gain?: number` (default 1)
   - `pan?: number` (default 0)

2. **GrainPlayer class extending TypedEventEmitter&lt;GrainPlayerEventMap&gt;:**
   - Constructor: `(audioContext: AudioContext, buffer: AudioBuffer, options?: GrainPlayerOptions)`
   - Creates shared output bus identical to PolySynth: `sharedBusInput -> [effects] -> masterGain -> masterPan -> [analyzer] -> destination`
   - Stores all options with defaults

3. **Grain scheduling loop:**
   - `play()`: Sets `_playing=true`, records startTime, begins `scheduleLoop()`
   - `scheduleLoop()`: Uses `setTimeout` at 25ms intervals. Calculates hop = grainSize - overlap (min 0.001). While `nextGrainTime < now + LOOKAHEAD (0.05s)`, calls `scheduleGrain(nextGrainTime)` and advances `nextGrainTime += hop`
   - `scheduleGrain(when)`: Creates `BufferSourceNode` from buffer, sets `playbackRate.value`. Creates per-grain `GainNode`. Applies Hann window: `gain.setValueAtTime(0.0001, when)`, `gain.linearRampToValueAtTime(1, when + grainSize/2)`, `gain.linearRampToValueAtTime(0.0001, when + grainSize)`. Connects: source -> grainGain -> sharedBusInput. Calculates offset: `position * buffer.duration + jitter scatter`. Clamps offset to buffer bounds. Calls `source.start(when, offset, grainSize / playbackRateValue)`. Increments `_activeGrainCount`. Adds `ended` listener to disconnect and decrement count.
   - `stop()`: Clears timer, sets `_playing=false`, `_paused=false`
   - `pause()`: Clears timer, sets `_paused=true`, `_playing` remains true
   - `resume()`: Restarts `scheduleLoop()`, sets `_paused=false`

4. **Property getters/setters:**
   - `position`: get/set with clamping to [0, 1]
   - `pitch`: get/set semitones, internally computes `playbackRateValue = Math.pow(2, semitones / 12)`
   - `playbackRate`: get/set ratio directly, updates internal `_pitch` accordingly
   - `grainSize`: get/set with min clamp to 0.01
   - `overlap`: get/set
   - `jitter`: get/set with clamp to [0, 1]
   - `loop`: get/set boolean
   - `playing`: readonly boolean
   - `paused`: readonly boolean
   - `activeGrainCount`: readonly number

5. **Master controls** (same pattern as PolySynth):
   - `update(type: 'gain' | 'pan')` with fluent `.to(value).as(method)` builder
   - `changeGainTo(value)`, `changePanTo(value)` direct setters
   - `addEffect()`, `removeEffect()`, `getEffects()` for effects chain
   - `setAnalyzer()`, `getAnalyzer()` for visualization
   - `setDestination()` for custom routing
   - `wireSharedBus()` private method (copy from PolySynth pattern)
   - `safeDisconnect()` private method

6. **Dispose:**
   - Stop playback, clear timer
   - Disconnect sharedBusInput, masterGain, masterPan
   - Clear effects array, null analyzer
   - Silence future events: `this.dispatchEvent = () => false`
   - Set `_disposed = true`

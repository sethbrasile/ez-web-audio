  <name>Task 2: Update GitHub Actions workflow for VitePress</name>
  <files>.github/workflows/deploy-docs-site.yml</files>
  <action>
Update the GitHub Actions workflow to build and deploy VitePress:

```yaml
# Simple workflow for deploying VitePress docs to GitHub Pages
name: Deploy VitePress docs to Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - name: Install dependencies
        run: pnpm install

      - name: Build library (needed for examples that import it)
        run: pnpm build:lib

      - name: Generate TypeDoc and build VitePress
        run: pnpm docs:build

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: docs/.vitepress/dist

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    needs: build
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

Key changes from old workflow:
1. Build library first (so Vue components can import ez-web-audio)
2. Run TypeDoc + VitePress build via `pnpm docs:build`
3. Upload from `docs/.vitepress/dist` (VitePress output directory)
4. Removed the old typedoc-only and manual mv commands
5. Split into build and deploy jobs (cleaner separation)

The base path `/ez-web-audio/` is set in VitePress config, not in the workflow.

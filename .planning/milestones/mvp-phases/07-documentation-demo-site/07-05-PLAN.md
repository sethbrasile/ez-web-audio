# Basic Playback

Learn how to play sounds and music tracks with EZ Web Audio.

## Playing a Sound

Sounds are perfect for short audio files like clicks, effects, and samples.
Each play creates a new audio source, so sounds can overlap.

<AudioDemo />

\`\`\`typescript
import { initAudio, createSound } from 'ez-web-audio'

document.querySelector('button')?.addEventListener('click', async () => {
  await initAudio()
  const sound = await createSound('/sounds/click.mp3')

  // Adjust before playing
  sound.changeGainTo(0.8)  // 80% volume
  sound.changePanTo(-0.5)  // Slightly left

  sound.play()
})
\`\`\`

### Key Features

- **Overlapping playback**: Call `play()` multiple times for layered sounds
- **Volume control**: `changeGainTo(0-1)` adjusts loudness
- **Stereo panning**: `changePanTo(-1 to 1)` positions in stereo field

## Playing a Track

Tracks are for longer audio like music. They support pause, resume, and seeking.

<TrackDemo />

\`\`\`typescript
import { initAudio, createTrack } from 'ez-web-audio'

const playBtn = document.querySelector('#play')
const pauseBtn = document.querySelector('#pause')
const seekBar = document.querySelector<HTMLInputElement>('#seek')

playBtn?.addEventListener('click', async () => {
  await initAudio()
  const track = await createTrack('/music/song.mp3')

  track.play()

  // Show position updates
  setInterval(() => {
    console.log(track.position.string)  // "1:23"
    console.log(track.percentPlayed)    // 0.35
  }, 100)
})

pauseBtn?.addEventListener('click', () => {
  track.pause()
})

seekBar?.addEventListener('input', (e) => {
  const target = e.target as HTMLInputElement
  track.seek(parseFloat(target.value))
})
\`\`\`

### Track Events

Tracks emit events for playback state changes:

\`\`\`typescript
track.on('play', (e) => console.log('Started at', e.detail.time))
track.on('pause', (e) => console.log('Paused at', e.detail.position))
track.on('resume', (e) => console.log('Resumed from', e.detail.position))
track.on('seek', (e) => console.log('Seeked to', e.detail.position))
track.on('end', () => console.log('Finished'))
\`\`\`

## Sound vs Track Comparison

| Feature | Sound | Track |
|---------|-------|-------|
| Best for | Short effects | Music, long audio |
| Overlapping | Yes | No |
| Pause/Resume | No | Yes |
| Seek | No | Yes |
| Position tracking | No | Yes |

# Sound Synthesis

Generate sounds from scratch using oscillators and ADSR envelopes.

## Basic Oscillator

Create pure tones with different waveforms. Try changing the frequency and waveform type:

<OscillatorDemo />

\`\`\`typescript
import { initAudio, createOscillator } from 'ez-web-audio'

document.querySelector('button')?.addEventListener('click', async () => {
  await initAudio()

  const synth = await createOscillator({
    frequency: 440,      // A4 note (Hz)
    type: 'sine'         // sine, square, sawtooth, triangle
  })

  synth.play()

  // Stop after 1 second
  setTimeout(() => synth.stop(), 1000)
})
\`\`\`

## Waveform Types

Each waveform has a distinct character:

| Type | Sound | Use Case |
|------|-------|----------|
| sine | Pure, smooth | Sub bass, pure tones |
| square | Hollow, buzzy | Retro games, leads |
| sawtooth | Bright, rich | Brass, strings |
| triangle | Soft, flute-like | Soft leads, bass |

## ADSR Envelopes

ADSR (Attack, Decay, Sustain, Release) shapes how a note evolves over time:
```
Volume
  ^
  |    /\
  |   /  \____
  |  /        \
  | /          \
  +--A--D--S--R--> Time
```

\`\`\`typescript
const piano = await createOscillator({
  frequency: 440,
  type: 'triangle',
  envelope: {
    attack: 0.01,    // Quick attack (piano hammer)
    decay: 0.1,      // Fast decay
    sustain: 0.7,    // Sustain at 70%
    release: 0.3     // Gentle release
  }
})

piano.play()
// When stop() is called, release phase begins
setTimeout(() => piano.stop(), 500)
\`\`\`

### Envelope Examples

**Piano/Keys** (sharp attack, quick decay):
\`\`\`typescript
{ attack: 0.01, decay: 0.2, sustain: 0.5, release: 0.3 }
\`\`\`

**Strings** (slow attack, full sustain):
\`\`\`typescript
{ attack: 0.3, decay: 0.1, sustain: 0.9, release: 0.5 }
\`\`\`

**Pad** (very slow attack, long release):
\`\`\`typescript
{ attack: 1.0, decay: 0.5, sustain: 0.7, release: 2.0 }
\`\`\`

**Pluck** (instant attack, no sustain):
\`\`\`typescript
{ attack: 0.001, decay: 0.3, sustain: 0, release: 0.1 }
\`\`\`

Common musical frequencies:

| Note | Frequency |
|------|-----------|
| C4 | 261.63 Hz |
| D4 | 293.66 Hz |
| E4 | 329.63 Hz |
| F4 | 349.23 Hz |

const a4 = frequencyMap.A4  // 440
\`\`\`

title: Effects
---

# Audio Effects

Add effects to any sound for professional audio processing.

## Built-in Effects

EZ Web Audio includes two built-in effects: GainEffect and FilterEffect.

### Gain Effect

Add a gain stage anywhere in the signal chain:

\`\`\`typescript
import { createSound, createGainEffect } from 'ez-web-audio'

const sound = await createSound('/audio/guitar.mp3')

// Create a gain effect at 50%
const boostEffect = createGainEffect(0.5)
sound.addEffect(boostEffect)

sound.play()
\`\`\`

### Filter Effect

Apply lowpass, highpass, bandpass, or notch filters:

\`\`\`typescript
import { createSound, createFilterEffect } from 'ez-web-audio'

const sound = await createSound('/audio/drums.mp3')

// Lowpass filter - removes high frequencies
const lowpass = createFilterEffect({
  type: 'lowpass',
  frequency: 1000,  // Cutoff at 1kHz
  Q: 1              // Resonance
})
sound.addEffect(lowpass)

sound.play()
\`\`\`

### Filter Types

| Type | Effect | Use Case |
|------|--------|----------|
| lowpass | Removes highs | Warm/muffled sound |
| highpass | Removes lows | Remove rumble |
| bandpass | Keeps middle | Telephone effect |
| notch | Removes specific freq | Remove hum |

## Effect Chain

Effects are processed in order added:

\`\`\`typescript
const sound = await createSound('/audio/synth.mp3')

// Signal path: source -> filter -> boost -> output
const filter = createFilterEffect({ type: 'lowpass', frequency: 2000 })
const boost = createGainEffect(1.5)

sound.addEffect(filter)
sound.addEffect(boost)

sound.play()
\`\`\`

## Managing Effects

\`\`\`typescript
// Add effect
sound.addEffect(effect)

// Remove specific effect
sound.removeEffect(effect)

// Clear all effects
sound.clearEffects()
\`\`\`

## External Effects

Use effects from external libraries like Tuna.js with `wrapEffect`:

\`\`\`typescript
import { wrapEffect } from 'ez-web-audio'
import Tuna from 'tunajs'

// Create Tuna instance (needs AudioContext)
const { initAudio, getAudioContext, createSound, wrapEffect } = await import('ez-web-audio')
await initAudio()
const audioContext = await getAudioContext()
const tuna = new Tuna(audioContext)

// Create a Tuna delay effect
const delay = new tuna.Delay({
  delayTime: 300,
  feedback: 0.4,
  wetLevel: 0.5
})

// Wrap it for use with EZ Web Audio
const sound = await createSound('/audio/vocals.mp3')
sound.addEffect(wrapEffect(delay))

sound.play()
\`\`\`

### Effect Wrapper Interface

The `wrapEffect` function accepts any object with `input` and `output` AudioNodes:

\`\`\`typescript
interface ExternalEffect {
  input: AudioNode     // Connect sound to this
  output: AudioNode    // This connects to next in chain
}

// Works with Tuna, Tone.js effects, or custom effects
const wrapped = wrapEffect(externalEffect)
\`\`\`

## Bypass and Mix

Control effect wet/dry mix:

\`\`\`typescript
const filter = createFilterEffect({ type: 'lowpass', frequency: 1000 })
sound.addEffect(filter)

// Bypass effect (100% dry)
filter.bypass = true

// Re-enable
filter.bypass = false

// Partial mix (50% wet, 50% dry)
filter.mix = 0.5
\`\`\`

## Visualization

Get frequency and waveform data for visualization:

\`\`\`typescript
import { createAnalyzer } from 'ez-web-audio'

const sound = await createSound('/audio/music.mp3')
const analyzer = createAnalyzer({ fftSize: 2048 })
sound.addEffect(analyzer)

sound.play()

// Get data for visualization
function draw() {
  const frequencies = analyzer.getFrequencyData()
  const waveform = analyzer.getTimeDomainData()

  // Use data for canvas visualization...

  requestAnimationFrame(draw)
}
draw()
\`\`\`

**SynthKeyboard.vue** - Layout shift when note name appears:

The `currentNote` div uses `v-if="currentNote"` (line 54), so it doesn't exist in the DOM until a note is pressed. When it appears, it pushes the keyboard down. Even though `.current-note` has `min-height: 2.5rem`, the div doesn't exist until `v-if` is truthy.

Fix: Change `v-if="currentNote"` to always render the div. Use a non-breaking space or placeholder text when empty:
```html
<div class="current-note">
  {{ currentNote || '&nbsp;' }}
</div>
```
Or simply remove the `v-if` and let the min-height handle the empty state. The `.current-note` CSS already has `min-height: 2.5rem` which will reserve the space.

**SampledDrumKit.vue** - Pads disappear during loading:

Lines 4-6: `<div v-if="loading" class="loading">` and line 6: `<div v-else class="drum-pads">` means pads are hidden during loading.

Fix: Remove the `v-if`/`v-else` pattern. Always show the drum pads. Show a loading indicator as an overlay or inline message, not as a replacement:
1. Remove `v-if="loading"` from the loading div
2. Remove `v-else` from the drum-pads div
3. Show both simultaneously - pads are always visible, loading text appears above/overlays when loading
4. Change loading div to show conditionally as a small overlay or status text above pads, not replacing them
5. Use `v-if="loading"` on a small status indicator inside or above the pads container
6. Keep pads always rendered, just disable interaction during loading via `:disabled` or pointer-events

**SoundfontPiano.vue** - Piano disappears during loading:

Lines 5-7: `<div v-if="loading" class="loading">` and line 9: `<div v-else class="piano-container">` - same pattern as SampledDrumKit.

Fix: Remove the `v-if`/`v-else` pattern:
1. Always render the `.piano-container` div (remove `v-else`)
2. Show loading text as a small overlay or status message within/above the piano, not replacing it
3. The PianoKeyboard component should always be visible
4. Add a small loading indicator (e.g., text below the note display) that shows during loading
5. Keep `v-if="loading"` on just the loading text element, positioned as a status message, not hiding the piano

**DistortionDemo.vue** - Wrong oscillator waveform:

Line 142: `type: 'sawtooth'` - Sawtooth is already harmonically rich, so adding distortion doesn't create an obvious difference.

Fix: Change `type: 'sawtooth'` to `type: 'sine'` on line 142. A sine wave is harmonically pure (single frequency), so distortion adds clearly audible harmonics - making the effect dramatically obvious.

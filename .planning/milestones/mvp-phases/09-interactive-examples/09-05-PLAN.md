    Initialization (on first note):
    ```typescript

    loadProgress.value = 'Loading piano soundfont (1.4MB)...'
    lib = await import('ez-web-audio')
    await lib.initAudio()
    font = await lib.createFont('/ez-web-audio/audio/piano.js')
    initialized.value = true
    loading.value = false
    ```

    Note handling:
    - On noteOn from PianoKeyboard: `font.play(note)` where note is like 'C4', 'Db4', etc.
      - CRITICAL: Font.play() expects note identifier string (e.g., 'C4'), NOT frequency. Per research pitfall #5.
      - Note naming: PianoKeyboard emits note names like 'C4', 'Db4' — make sure these match Font's expected identifiers. The Font uses the note's `identifier` property which follows the `letter + accidental + octave` pattern.
      - Check if Font uses 'Db4' or 'C#4' — the library's frequencyMap uses flats (Db, Eb, Gb, Ab, Bb). Font notes should match.
    - On noteOff: For sampled notes, they naturally decay — no explicit stop needed. But update activeNotes set for visual feedback.
    - Add note to activeNotes set on noteOn, remove on noteOff.

    Template:
    ```

    Keyboard hint: "Use keys A-K to play"
    "Compare with [Synth Keyboard] which uses oscillators instead of samples"
    ```

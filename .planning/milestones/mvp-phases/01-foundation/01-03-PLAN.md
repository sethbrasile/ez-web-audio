Add Node.js EventEmitter-style convenience methods per CONTEXT.md decisions:

1. Chainable .on() supporting single or multiple events:
   ```typescript
   /**
    * Subscribe to one or more events. Supports chaining.
    * @example
    * sound.on('play', handlePlay).on('stop', handleStop);
    * sound.on(['play', 'stop'], handleBoth);
    */
   on<K extends keyof SoundEventMap>(
     type: K | K[],
     listener: (event: SoundEventMap[K]) => void
   ): this {
     if (Array.isArray(type)) {
       type.forEach(t => this.addEventListener(t, listener as any));
     } else {
       this.addEventListener(type, listener);
     }
     return this;
   }
   ```

2. .once() for single-fire subscriptions:
   ```typescript
   /**
    * Subscribe to an event once. Handler is removed after first invocation.
    */
   once<K extends keyof SoundEventMap>(
     type: K,
     listener: (event: SoundEventMap[K]) => void
   ): this {
     this.addEventListener(type, listener, { once: true });
     return this;
   }
   ```

3. .off() with dual unsubscribe pattern:
   ```typescript
   /**
    * Unsubscribe from an event.
    * With handler: removes specific handler
    * Without handler: removes ALL handlers for that event type (if tracking enabled)
    */
   off<K extends keyof SoundEventMap>(
     type: K,
     listener?: (event: SoundEventMap[K]) => void
   ): this {
     if (listener) {
       this.removeEventListener(type, listener);
     }
     // Note: Removing ALL listeners without a reference is not supported by native EventTarget
     // Document this limitation or implement listener tracking in future
     return this;
   }
   ```

4. Add optional removeAllListeners():
   ```typescript
   /**
    * Remove all event listeners.
    * Note: Only works for listeners added via .on() if listener tracking is implemented.
    * Currently a no-op placeholder for future implementation.
    */
   removeAllListeners(): this {
     // TODO: Implement listener tracking if needed
     // For now, document that users should store listener references for cleanup
     return this;
   }
   ```

Per CONTEXT.md, document that .off() without handler and removeAllListeners() are limited by native EventTarget. Users should store listener references if they need to remove them.

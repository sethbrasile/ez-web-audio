<feature>
  <name>LayeredSound - synchronized multi-voice playback</name>
  <files>src/layered-sound.ts, src/layered-sound.test.ts, src/events/event-types.ts, src/index.ts</files>
  <behavior>
    LayeredSound wraps multiple Sound/Oscillator instances and plays them in perfect sync.

    **Construction:**
    - `new LayeredSound(audioContext, layers, opts?)` accepts array of Sound|Oscillator
    - Filter out null/undefined layers (graceful degradation)
    - Emit 'warning' event if any layers failed to load
    - Soft limit warning at 8+ layers (configurable via opts.warnLayerCount)
    - Layers are static - fixed at construction, no add/remove during playback

    **Playback (critical sync mechanism):**
    - `play()` captures `startTime = audioContext.currentTime` FIRST, then calls `playAt(startTime)` on all layers - this is the exact sync pattern from RESEARCH.md Pattern 1
    - All layers receive the SAME startTime value (not separate currentTime calls per layer)
    - `stop()` calls `stop()` on all layers
    - Reusable - each play() creates fresh source nodes (like Sound pattern)

    **Events:**
    - Emits 'play' when play() called (before layers start)
    - Emits 'stop' when stop() called
    - Emits 'end' when LAST layer finishes (layers end independently)
    - Use once('end') on each layer, track in Set, emit when all complete

    **Master controls:**
    - `setGain(value)` calls changeGainTo on all layers
    - `setPan(value)` calls changePanTo on all layers

    **Layer access:**
    - `getLayer(index)` returns Sound|Oscillator|undefined
    - `layerCount` getter returns number of valid layers

    **Event types (add to event-types.ts):**
    - LayeredSoundEventMap with play, stop, end, warning events
    - WarningEventDetail with message, failedLayers, source

    **Test cases:**
    - Construction with mixed Sound/Oscillator layers
    - Construction with null/undefined layers (graceful degradation + warning event)
    - Construction with 8+ layers (console.warn emitted)
    - play() calls playAt on all layers with same time
    - stop() calls stop on all layers
    - setGain/setPan affect all layers
    - getLayer returns correct layer or undefined
    - layerCount returns correct count
    - play event emitted on play()
    - stop event emitted on stop()
    - end event emitted when last layer finishes
    - Multiple play() calls work (reusable)
  </behavior>

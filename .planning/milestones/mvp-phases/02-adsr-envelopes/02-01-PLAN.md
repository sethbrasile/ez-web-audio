<feature>
  <name>Envelope class with ADSR logic</name>
  <files>src/envelope.ts, src/envelope.test.ts</files>
  <behavior>
    Envelope class manages ADSR timing and AudioParam scheduling:

    Constructor accepts EnvelopeOptions:
    - attackTime: number (default 0.01) - seconds to ramp from 0 to peak
    - decayTime: number (default 0.1) - seconds to ramp from peak to sustain
    - sustainLevel: number (default 0.7) - amplitude level 0-1 during hold
    - releaseTime: number (default 0.3) - seconds for release to silence

    applyTo(gainParam: AudioParam, startTime: number): void
    - Sets value to 0 at startTime
    - Linear ramp to 1 (peak) at startTime + attackTime
    - Linear ramp to sustainLevel at startTime + attackTime + decayTime
    - Returns nothing, sustain holds until release() called

    release(gainParam: AudioParam, releaseTime: number): void
    - Uses setTargetAtTime(0, releaseTime, this.releaseTime / 5)
    - Time constant = releaseTime/5 gives 99% completion in releaseTime

    Test cases:
    - Constructor defaults: attackTime=0.01, decayTime=0.1, sustainLevel=0.7, releaseTime=0.3
    - Custom values respected
    - applyTo schedules: setValueAtTime(0), linearRamp(1, attack), linearRamp(sustain, decay)
    - release schedules: setTargetAtTime(0, time, releaseTime/5)
    - Sustain level validated 0-1 range (clamp, don't throw)
    - Zero attackTime works (immediate peak)
    - Zero decayTime works (immediate sustain)
  </behavior>

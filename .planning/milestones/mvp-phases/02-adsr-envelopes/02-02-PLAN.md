  <files>src/controllers/oscillator-controller.ts</files>
  <action>
    Add envelope lifecycle management to OscillatorController:

    1. Import Envelope from envelope.ts
    2. Add private property: `private envelope?: Envelope`
    3. Add method: `setEnvelope(envelope: Envelope): void`
    4. Modify setValuesAtTimes() to apply envelope BEFORE other parameter automation:
       ```typescript
       public setValuesAtTimes(): void {
         const { oscillator: { context: { currentTime } } } = this

         // Apply envelope first (sets initial gain to 0, schedules ramps)
         if (this.envelope) {
           this.envelope.applyTo(this.gainNode.gain, currentTime)
         }

         // Then apply other parameter automation
         this.applyValues(this.startingValues, currentTime)
         this.applyValues(this.valuesAtTime, currentTime)
         this.applyRampValues(this.exponentialValues, currentTime, 'exponential')
         this.applyRampValues(this.linearValues, currentTime, 'linear')
       }
       ```
    5. Add method for release phase:
       ```typescript
       public triggerRelease(releaseTime: number): void {
         if (this.envelope) {
           this.envelope.release(this.gainNode.gain, releaseTime)
         }
       }
       ```

    The controller manages envelope state; Oscillator calls controller methods.
  </action>

  <action>
    Override stop methods to trigger envelope release before stopping:

    1. Override stop() method:
       ```typescript
       public async stop(): Promise<void> {
         if (this.envelope && this._isPlaying) {
           const releaseTime = this.audioContext.currentTime
           this.controller.triggerRelease(releaseTime)
           // Schedule actual stop after release completes
           const releaseEndTime = releaseTime + this.envelope.releaseTime
           await this.stopAt(releaseEndTime)
         } else {
           await super.stop()
         }
       }
       ```

    2. Consider stopAt/stopIn - they should also respect envelope if playing:
       For simplicity in v1, only override stop(). Document that stopAt/stopIn
       bypass envelope release (advanced users can call controller.triggerRelease directly).

    Important: The envelope's releaseTime determines how long to wait before
    actually stopping the oscillator node. This prevents cutting off the release tail.

    If no envelope, delegate to super.stop() unchanged.

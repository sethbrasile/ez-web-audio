<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Configure npm token in GitHub secrets</name>
  <what-needed>
User must create NPM_TOKEN secret in GitHub repository settings for automated publishing to work.
  </what-needed>
  <instructions>
1. **Get npm token:**
   - Go to https://www.npmjs.com/ and log in (create account if needed)
   - Click your profile avatar -> Access Tokens
   - Click "Generate New Token" -> "Classic Token"
   - Select "Automation" type (best for CI)
   - Copy the token (you won't see it again)

2. **Add to GitHub secrets:**
   - Go to your GitHub repository: https://github.com/sethbrasile/ez-web-audio
   - Settings -> Secrets and variables -> Actions
   - Click "New repository secret"
   - Name: `NPM_TOKEN`
   - Value: paste the npm token
   - Click "Add secret"

3. **Verify secret exists:**
   - The secret should appear in the list (value hidden)
  </instructions>
  <resume-signal>Type "configured" when NPM_TOKEN secret is added to GitHub</resume-signal>
</task>

<task type="auto">
  <name>Task 1: Update Vite config for ESM-only library build</name>
  <files>vite.config.js</files>
  <action>
Update vite.config.js to configure library mode for ESM-only output:

1. Update dtsPlugin() to dts() with options:
   - `rollupTypes: false` (keep per-file declarations for better IDE "Go to Definition")
   - `declarationMap: true` (enable .d.ts.map files)
   - `insertTypesEntry: true` (auto-add types entry)

2. Update build.lib configuration:
   - `formats: ['es']` (ESM-only per CONTEXT decision)
   - `fileName: 'index'` (produces index.js)

3. Add build options:
   - `sourcemap: true` (external source maps)
   - `minify: false` (don't minify - consumers handle this)
   - `rollupOptions: { external: [] }` (no dependencies to externalize)

The final config should look like the RESEARCH.md pattern but preserve existing tsconfigPaths() and test configuration.
  </action>
  <verify>
Run `pnpm build:lib` - should complete without errors and produce:
- dist/index.js (ESM bundle)
- dist/index.js.map (source map)
- dist/index.d.ts (type declarations)
- dist/index.d.ts.map (declaration map)
  </verify>
  <done>
Vite builds ESM-only library with external source maps and declaration maps. No UMD/CJS output.
  </done>
</task>

<task type="auto">
  <name>Task 2: Update package.json for modern npm distribution</name>
  <files>package.json</files>
  <action>
Update package.json to use modern npm package conventions:

1. Update version:
   - Change `"version": "0.0.0-notready"` to `"version": "0.1.0"` per CONTEXT decision

2. Simplify exports field (ESM-only, no require fallback):
   ```json
   "exports": {
     ".": {
       "types": "./dist/index.d.ts",
       "import": "./dist/index.js"
     }
   }
   ```

3. REMOVE legacy fields (per CONTEXT "no legacy main/module fallback"):
   - Remove `"main": "./dist/index.cjs"`
   - Remove `"module": "./dist/index.js"`
   - Keep `"types": "./dist/index.d.ts"` (some older tools still use it)

4. Add sideEffects field for tree-shaking:
   - Add `"sideEffects": false` at top level

5. Update files field to whitelist (per RESEARCH recommendation):
   ```json
   "files": [
     "dist",
     "README.md",
     "LICENSE"
   ]
   ```

6. Remove `"private": false` (default is false, explicit false is redundant)

7. Add prepublishOnly script:
   ```json
   "prepublishOnly": "pnpm build:lib"
   ```

Preserve all other fields (name, type, description, author, license, repository, keywords, scripts, devDependencies, packageManager).
  </action>
  <verify>
Run `npm pkg get exports` - should show the simplified exports structure.
Run `npm pkg get sideEffects` - should show false.
  </verify>
  <done>
Package.json uses modern exports field (ESM-only), has sideEffects: false for tree-shaking, files whitelist configured, version set to 0.1.0.
  </done>
</task>

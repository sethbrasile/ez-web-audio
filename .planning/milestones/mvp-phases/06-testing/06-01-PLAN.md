<task type="auto">
  <name>Task 2: Create Track class tests</name>
  <files>src/track.test.ts</files>
  <action>
Create new test file for Track class. Track extends Sound and adds position tracking, pause/resume, and seek.

Add test suites for:

1. **Creation:**
   - Creates Track from AudioBuffer
   - Inherits Sound behavior

2. **Position tracking:**
   - `position` returns TimeObject with raw, string, pojo
   - `percentPlayed` returns correct percentage
   - Position updates during playback (may need fake timers)

3. **Pause/Resume:**
   - `pause()` stops playback but preserves position (startOffset > 0)
   - `pause()` emits 'pause' event with position
   - `resume()` continues from paused position
   - `resume()` emits 'resume' event with position
   - Multiple pause/resume cycles work correctly
   - `resume()` does nothing if not paused (startOffset === 0)

4. **Stop:**
   - `stop()` resets startOffset to 0
   - `stop()` cancels RAF loop (no memory leak)
   - Stop after pause resets position

5. **Seek:**
   - `seek(0.5).from('ratio')` moves to 50% of duration
   - `seek(50).from('percent')` moves to 50% of duration
   - `seek(10).from('seconds')` moves to 10 seconds
   - `seek(0.25).from('inverseRatio')` moves to 75% of duration
   - Seek emits 'seek' event with position and previousPosition
   - Seek while playing restarts at new position
   - Seek while paused updates position without playing
   - Seek clamps to valid range (0 to duration)

6. **Event payloads:**
   - Pause event includes { time, source, position }
   - Resume event includes { time, source, position }
   - Seek event includes { time, source, position, previousPosition }

Use settle() helper for async assertions. Use vi.useFakeTimers() if testing RAF-based position updates.

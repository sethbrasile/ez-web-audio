  <name>Task 1: Create Sampler class tests</name>
  <files>src/sampler.test.ts</files>
  <action>
Create new test file for Sampler class. Sampler provides round-robin playback of multiple sounds.

Add test suites for:

1. **Creation:**
   - Creates Sampler from array of sounds
   - Accepts optional name in options
   - Default gain is 1
   - Default pan is 0

2. **Round-robin behavior:**
   - `play()` calls play on first sound
   - Second `play()` calls play on second sound
   - Third `play()` calls play on third sound
   - After exhausting all sounds, loops back to first
   - Works with 1 sound (always plays same sound)
   - Works with 2+ sounds

3. **Play methods:**
   - `play()` immediately plays next sound
   - `playIn(seconds)` schedules next sound
   - `playAt(time)` schedules at specific time
   - Each play method advances the iterator

4. **Gain and pan control:**
   - Setting `sampler.gain = 0.5` applies to next played sound
   - Setting `sampler.pan = -1` applies to next played sound
   - Gain/pan applied via `setGainAndPan()` to each sound before play
   - Verify using spies on `changeGainTo` and `changePanTo`

5. **Edge cases:**
   - Empty sounds array behavior (document or handle gracefully)
   - Single sound loops correctly
   - Sounds can be any Playable & Connectable

Use spies (vi.spyOn) to verify play methods called on correct sounds.
Create mock sounds with play/playIn/playAt/changeGainTo/changePanTo methods.

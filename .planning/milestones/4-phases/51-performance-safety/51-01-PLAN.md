## Context

Four performance requirements from the deep review:

1. **PERF-02**: `duration` getter allocates a `TimeObject` (calls `createTimeObject()` with string formatting via `zeroify`) on every access. Hot paths like `playAt()`, `stopAt()`, `trackPlayPosition()`, and `percentPlayed` only need `duration.raw` (a number). Add a `durationRaw` numeric getter to avoid allocation.

2. **PERF-04**: `audioContext.resume()` is called unconditionally in `playAt()` (line 891) and `stopAt()` (line 1010) in `base-sound.ts`. It should only be called when `audioContext.state === 'suspended'`.

3. **PERF-05**: `AudioSprite.play()` always creates both a `GainNode` and `StereoPannerNode` even when gain=1 and pan=0 (defaults). Skip node creation when at defaults.

4. **PERF-06**: `crossfade()` in `src/utils/crossfade.ts` calls `generateEqualPowerCurve()` on every invocation with the same parameters (`curveLength=256`). Cache the curves at module level.

1. **PERF-02 — Add `durationRaw` getter to Sound**

   In `src/sound.ts`, add a new public getter above the existing `duration` getter:

   ```typescript
   /**
    * Get the duration of the audio buffer in seconds.
    *
    * Use this instead of `duration.raw` in performance-sensitive code paths
    * to avoid allocating a TimeObject.
    */
   public get durationRaw(): number {
     const buffer = this.audioSourceNode.buffer
     return buffer === null ? 0 : buffer.duration
   }
   ```

   Then refactor the existing `duration` getter to use it:

   ```typescript
   public get duration(): TimeObject {
     const raw = this.durationRaw
     if (raw === 0) return createTimeObject(0, 0, 0)
     const min = Math.floor(raw / 60)
     const sec = raw % 60
     return createTimeObject(raw, min, sec)
   }
   ```

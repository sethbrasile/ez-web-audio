## Context

Four remaining safety requirements from the deep review:

1. **SAFE-07**: `getOrCreateAudioContext()` silently creates a new AudioContext when the previous one closed. It should log a console warning about potentially orphaned sounds.

2. **SAFE-08**: `dispose()` does not clear event listeners. Since `TypedEventEmitter` extends native `EventTarget` (which has no `removeAllListeners()`), the cleanest approach is to document that consumers should call `off()` before `dispose()`, AND add a no-op override of `dispatchEvent` in `dispose()` so that even if listeners remain, they will not fire on a disposed instance.

3. **SAFE-09**: `LayeredSound` has no `dispose()` method. It should stop all layers, dispose them, clear internal state, and prevent further use.

4. **SAFE-10**: `changePanTo()` accepts any number without validation. Values outside `[-1, 1]` should log a console warning (similar to how `changeGainTo()` warns for values > 1).

## Current State

- `getOrCreateAudioContext()` in `src/audio-context.ts` (line 24-28): Creates new context when `_audioContext` is null or closed, no warning.
- `dispose()` in `src/base-sound.ts` (lines 1218-1260): Stops playback, disconnects nodes, clears effects. Does NOT clear event listeners or prevent future event dispatch.
- `LayeredSound` in `src/layered-sound.ts`: Has `stop()` and `play()` methods but no `dispose()`.
- `changePanTo()` in `src/base-sound.ts` (line 655-658): Delegates to controller with no validation.

1. **SAFE-07 — Warn on AudioContext replacement**

   In `src/audio-context.ts`, update `getOrCreateAudioContext()`:

   ```typescript
   export function getOrCreateAudioContext(): AudioContext {
     if (!_audioContext || _audioContext.state === 'closed') {
       if (_audioContext?.state === 'closed') {
         console.warn(
           'ez-web-audio: Previous AudioContext was closed. Creating a new one. '
           + 'Any sounds created with the old context are now orphaned and should be disposed.',
         )
       }
       _audioContext = new AudioContext()
     }
     return _audioContext
   }
   ```

   The key change: only warn when `_audioContext` exists AND its state is `'closed'` (not on first creation when `_audioContext` is null).

2. **SAFE-08 — Silence events after dispose**

   In `src/base-sound.ts`, at the end of the `dispose()` method (before `this._disposed = true`), add a `dispatchEvent` override that no-ops:

   ```typescript
   // Silence future event dispatch so listeners cannot fire on a disposed instance.
   // EventTarget has no removeAllListeners(), so we override dispatchEvent instead.
   this.dispatchEvent = () => false
   ```

   This ensures that even if `emit()` is called (e.g., from a delayed timeout that wasn't caught), no listener will fire.

   Also add a JSDoc note to the `dispose()` method:

   ```
   * After disposal, event listeners registered via `on()` / `addEventListener()` will
   * no longer fire. To free listener references for garbage collection, call `off()` for
   * each listener before calling `dispose()`.
   ```

1. **SAFE-09 — Add `dispose()` to LayeredSound**

   In `src/layered-sound.ts`, add a `dispose()` method and a `_disposed` flag:

   Add private field near the top of the class:
   ```typescript
   private _disposed = false
   ```

   Add a `disposed` getter:
   ```typescript
   /**
    * Whether this LayeredSound has been disposed.
    */
   get disposed(): boolean {
     return this._disposed
   }
   ```

   Add the `dispose()` method after `setPan()`:

   ```typescript
   /**
    * Stop all layers and dispose them. Releases resources and prevents further use.
    *
    * After disposal, calling play() will throw an error.
    * Dispose is idempotent — calling it multiple times is safe.
    *
    * @example
    * ```typescript
    * const layered = await createLayeredSound([bass, melody])
    * layered.play()
    * // When done:
    * layered.dispose()
    * ```
    */
   dispose(): void {
     if (this._disposed) return

     // Stop all layers
     this.layers.forEach((layer) => {
       try {
         layer.stop()
       }
       catch {
         // Already stopped
       }
     })

     // Dispose all layers
     this.layers.forEach((layer) => {
       if ('dispose' in layer && typeof layer.dispose === 'function') {
         layer.dispose()
       }
     })

     // Clean up layer end tracking
     this.layerEndHandlers.forEach((handler, layer) => {
       layer.off('end', handler)
     })
     this.layerEndHandlers.clear()

     // Clear layers array
     this.layers = []
     this.failedLayers = []

     // Silence future events
     this.dispatchEvent = () => false

     this._disposed = true
   }
   ```

   Add a dispose guard to `play()` at the top:
   ```typescript
   if (this._disposed) {
     throw new Error('Cannot play a disposed LayeredSound. Create a new instance.')
   }
   ```

   Add the same guard to `playFor()`, `stop()`, `setGain()`, `setPan()`.

2. **SAFE-10 — Warn on out-of-range pan values**

   In `src/base-sound.ts`, update `changePanTo()` (line 655):

   public changePanTo(value: number): this {
     if (value < -1 || value > 1) {
       console.warn(
         `ez-web-audio: Pan value ${value} is outside the [-1, 1] range. `
         + 'Values are clamped by the Web Audio API. Use -1 (left) to 1 (right).',

     return this
   }

**SAFE-03 — BeatTrack.dispose():**

Add a `dispose()` method to `BeatTrack` class:

```typescript
/**
 * Dispose this BeatTrack, stopping playback, clearing beats,
 * and releasing all audio resources.
 *
 * After disposal, the BeatTrack should not be used. Create a new instance instead.
 */
public dispose(): void {
  // Stop playback (clears timerID, resets beat index, cancels beat timers)
  this.stop()

  // Dispose all underlying sounds in the sampler
  for (const sound of this.sounds) {
    if ('dispose' in sound && typeof (sound as any).dispose === 'function') {
      (sound as any).dispose()
    }
  }
  this.sounds.clear()

  // Clear beats array
  this._beats = []

  // Clear event target by replacing it (no removeAllListeners on EventTarget)
  this.eventTarget = new EventTarget()
}
```

Note: `_beats` is private, so the dispose method has access. `sounds` is `protected` from Sampler. The `eventTarget` is private to BeatTrack. The `dispose()` method checks for dispose on each sound because the Sampler's sounds implement `Playable & Connectable` — not all necessarily have `dispose()`, but Sound instances (which is what BeatTrack typically holds) do.

**SAFE-06 — LayeredSound.play() with allSettled:**

In `src/layered-sound.ts`, change the `play()` method:

Replace:
```typescript
await Promise.all(
  this.layers.map(layer => layer.playAt(startTime)),
)
```

With:
```typescript
const results = await Promise.allSettled(
  this.layers.map(layer => layer.playAt(startTime)),
)

// Track which layers failed during this play call
const playFailures = results
  .map((result, index) => ({ result, index }))
  .filter((item): item is { result: PromiseRejectedResult, index: number } =>
    item.result.status === 'rejected',
  )
  .map(({ result, index }) => ({
    index,
    error: result.reason instanceof Error ? result.reason : new Error(String(result.reason)),
  }))

if (playFailures.length > 0) {
  this.emit('warning', {
    message: `${playFailures.length} layer(s) failed to play`,
    failedLayers: playFailures,
    source: this,
  })
}
```

This ensures that even if one layer's `playAt()` rejects (e.g., AudioContext closed, disposed sound), the other layers still play. The warning event notifies consumers of partial failures.
